# 安全致谢

## 引言

感谢独立安全研究人员和安全社区成员以负责任的方式报告问题，并帮助 ComiCine 改进安全。我们感谢研究人员为提升安全所作的审慎贡献。

## 致谢政策

- 对于负责任披露并经核实的安全漏洞，我们可能公开致谢。
- 是否公开致谢由 ComiCine 酌情决定。
- 未经研究人员同意，我们不会公开其姓名或其他可识别身份的信息。研究人员可以选择匿名致谢。
- 致谢不代表提供金钱补偿。
- ComiCine 可以不公开可能暴露敏感信息的漏洞细节。

## 致谢名单

未来的致谢条目可能包括研究人员姓名或偏好的别名、贡献摘要、致谢日期，以及经本人同意后提供的个人网站或资料链接。

目前尚未发布公开的安全致谢。

## 报告信息

请先阅读[安全漏洞披露政策](/security/policy/zh-cn)，了解报告方式和研究指南。
