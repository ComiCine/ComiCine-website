# Security Acknowledgments

## Introduction

Thank you to the independent security researchers and members of the security community who responsibly report issues and help improve ComiCine's security. We appreciate the care researchers take in contributing to security improvements.

## Recognition Policy

- Recognition may be offered for responsibly disclosed and verified security vulnerabilities.
- Whether to publish an acknowledgment is at ComiCine's discretion.
- We will not publish a researcher's name or other identifying information without their consent. Researchers may request anonymous acknowledgment.
- Recognition does not imply monetary compensation.
- ComiCine may choose not to publish vulnerability details that could expose sensitive information.

## Acknowledgments List

Future entries may include a researcher's name or preferred alias, a contribution summary, the recognition date, and an optional personal website or profile link when the researcher consents to its publication.

No public security acknowledgments have been published yet.

## Reporting Information

Please read the [Security Vulnerability Disclosure Policy](/security/policy/en-us) for reporting instructions and research guidelines.
