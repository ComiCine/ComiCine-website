# 보안 감사의 글

## 소개

문제를 책임 있게 제보하고 ComiCine의 보안 개선에 도움을 주시는 독립 보안 연구자와 보안 커뮤니티 구성원께 감사드립니다. 보안 향상을 위해 신중하게 기여해 주셔서 감사합니다.

## 공개 및 감사 정책

- 책임 있게 공개되어 검증된 보안 취약점에 대해 공개적으로 감사를 표할 수 있습니다.
- 공개 감사 여부는 ComiCine의 재량에 따릅니다.
- 연구자의 동의 없이 이름이나 그 밖의 신원을 확인할 수 있는 정보를 공개하지 않습니다. 익명으로 감사받기를 요청할 수 있습니다.
- 감사 표시는 금전적 보상을 의미하지 않습니다.
- 민감한 정보가 노출될 수 있는 취약점 세부 내용은 공개하지 않을 수 있습니다.

## 감사 목록

향후 감사 항목에는 연구자의 이름 또는 선호하는 별칭, 기여 요약, 감사 날짜, 그리고 본인이 공개에 동의한 경우 선택적으로 개인 웹사이트나 프로필 링크가 포함될 수 있습니다.

아직 공개된 보안 감사 항목이 없습니다.

## 제보 안내

제보 방법과 연구 지침은 [보안 취약점 공개 정책](/security/policy/ko-kr)을 확인해 주세요.
