# MU5735 / DCA22WA102 資料調査報告


::: tip 読み進め方

要約と主要な時系列から読む場合は、§0 要約 → §2 時系列 → §4 FDRイベント → §5 ARINC 717デコード → §6 レーダー・物理・衝突 → §9 矛盾 → §10 限界と結論の順。技術的詳細は§4–§7、調査経緯は§8を参照。全章はページ内目次に表示される。

:::

## 0. 要約

2022-03-21、中国東方航空 MU5735便（B-737-800、B-1791、昆明 ZPPP → 広州 ZGGG）が広西チワン族自治区梧州市内に墜落し、乗客123人、乗員9人の全員が死亡した。事故調査は附属書13に基づき CAAC が主導し、NTSB が協力した。事故から4年後の2026年4月、NTSBは49 U.S.C. §1114(f) に基づき、1,959ページの記録、FDR表2点、FDR原ファイル3点を公開した。

::: info 1分でたどる経過

高度29,103 ftで巡航 → 両エンジンの燃料コントロールスイッチが CUTOFF に切り替わる → 約1.8秒後に操縦輪が−28°まで左に操作され、その後も左操作と戻しを反復し、機体は左ロールを継続 → 左ロール約1.45回転、ピッチ−36°の急降下 → 発電機が電源系統から切り離され、FDRは高度25,389 ftで記録停止 → レーダーは毎分21,600 ftの降下を記録 → 06:21:40が最終観測点、衝突は約06:22:30。操縦室用音声記録装置（CVR）には最後の約70–97秒が記録されていたはずだが、音声は中国側が保有している。

:::

**資料が裏付ける事実関係：**

1. 高度29,103 ftで巡航中、**両エンジンの燃料コントロールスイッチが同一の1秒サンプリング窓内に RUN から CUTOFF に変化**した。その後、N2は92.4%から49.9%（Eng1）／52.5%（Eng2）へ単調に低下し、N1は83.5%から25.6%／25.8%へ、EGTは623°Cから395／397°Cへ低下、燃料流量は0になった。**スラストレバー角度は全期間58.9–60.1°で、スラストレバー操作はなかった。**
2. 燃料遮断から約1.8秒後、最初の有効な操縦入力サンプルとして**操縦輪−28.1°**を記録。その後は−19°～−102°の範囲で反復し、最大−101.95°、中央値は約−47°。補助翼は比例して追従し、最大偏向は約+17.8°／−18.4°。**ロールは同じ左方向に継続し、16.3秒間で累積約−528°～−540°（約1.45–1.50回転）、平均−32 ± 2°/s。ピッチは+2.46°から−35.86°へ、IASは265 ktから339.75 ktへ、高度は29,103 ftから25,389 ftへ変化した。**
3. **事故時、機体システムは作動していた。**油圧Aは2,960–3,004 psi、Bは2,972–3,016 psi。補助翼、昇降舵、操縦輪、操縦桿はいずれも入力に追従した。有効データでは両エンジンの火災警報は NO FIRE、両エンジンは同期して出力が低下し、片側エンジンが先に故障した形跡はない。
4. **発電機が電源系統から切り離されたため、FDRは高度約25,389 ftで記録を停止した。**N2の切離ししきい値は約49%（48.6–49.9%、**推定**）、時刻は約06:21:06–07Z。レーダーの最終実測点は06:21:40Z、高度3,380 mであり、記録停止後も機体は約4,300 m降下した。
5. **CVRの4チャンネルはすべて Excellent**（音声パネル3系統は各約120分、CAMは約180分）。NTSBはCVRを受領して自らデータを読み出した後、音声一式をCAACに返却し、NTSB側では保管しなかった。FOIA回答書も、NTSBがCVRデータを一切保有していないと明記している。**したがって、この公開資料には音声も書き起こしも含まれない。**
6. **2026-04の公開時点で、最終報告書は公表されていなかった。**第8巻のメールでは2024-03-21時点でも報告書の予定を問い合わせているが、CAACから回答はない。2024年のメールで明確に記されているのは “since a final report has yet to be issued” の一文のみ。2024-03-20のCAAC二周年発表は「離陸前、航空機システム、機体構造、エンジン等に故障・異常は確認されなかった」と述べるが、原因に関する結論や報告書の予定は示していない。

::: warning 証拠の限界

現有資料では、誰が操作したのか、動機は何か、意図的だったかどうかを証明できない。FDRが示すのは、燃料スイッチ位置のパラメータが変化し、機体がそのように操縦されたことまでであり、意図的な操作、操縦不能、争い、機械的／電気的な共通原因故障を区別できない。重要な手掛かりとなるCVRは中国側が保有している。事故原因を認定する権限を持つ機関はCAACである。

:::

### 1.2 OCR と派生データ

公開されたスキャン資料はすべて画像のみ（1275×1650 JPEG、150 dpi、テキストレイヤーなし）で、全ページにOCRを実施。重要な52ページ（vol1 p1–33、vol8 p157–175）は**300 dpiで再OCRし、重要値47項目を切り出して目視確認**したが、数字／部品番号／時刻／重量のいずれも覆らなかった（CVR/FDRのP/N、120/120/120/180 min、6.5+1.3 s、26,000 ft、TOW 66,039、PAX 123、乗員の飛行時間、レーダー3,380 m／1,010 km/h／117.8°）。300 dpi OCRで修正されたのは 音声ファイル形式表記などの文字認識13箇所で、fをtと誤認した12箇所も新たに見つかった。そのため本文は主に144 dpiの結果を使用し、音声ファイル形式表記は300 dpiを採用。PPTの `CABINE`／`EXRA`／`PLANED` は原資料の誤植であり、OCR誤りではない。写真の刻印、チップのシルク印刷、p25–27の曲線軸は、どちらの解像度でも信頼できず引用しない。FDRの2種類の表データは全列を監査済み。ARINC 717の3区間は構造を解析してデコード済み。これらの結果は関連する派生データとも照合した。

## 2. 時系列（絶対時刻と範囲）

### 2.1 時刻基準

- CAAC／ATCの時刻は北京時間（UTC+8）、ACARSはUTC、FOIAメールは米東部夏時間（EDT、UTC−4）。
- FDR の `Time (sec)` は記録装置内部のカウンター（288,200–288,978秒）であり、時計時刻ではない。記録末尾とレーダー情報を使って逆算する。
- **ARINC 717データのブロック長は1.000秒／ブロックと判定**（U2の欠測周期8ブロック = NTSBの8秒、全区間の高度適合はB=1.0、B=1.0195ではRMS 12,980 ft）。前便の着陸記録を含むデータの一部は例外で時間軸が1.385倍に引き延ばされているため、絶対時刻の照合には使えない。

## 3. NTSB Cockpit Voice and Flight Data Recorder Combined Download Report（33ページ、2022-07-01）

### 3.1 CVR（操縦室用音声記録装置、Honeywell HFR5-V、P/N 980-6032-001、S/N CVR-04014）

- 3月23日に発見。衝突による損傷が激しく、中国側は北京で代替ケースを使って複数回読み出しを試みたが失敗。
- NTSBが3月28日にCVRデータを受領。Playback32で4つの音声トラックを復号したが **unintelligible / unusable（判読不能／使用不能）**（p5）。
- 顕微鏡検査：コネクターのはんだパッド破断、ピン変形、グラウンド層断裂。ケースを開けるとさらに多くのピンが押しつぶされていた。製造時点ですでに電源フィルター用コンデンサー1個のはんだが外れていた。
- コネクター修理後、DLDRチップイメージとPlayback32を使い、**Fair（音声パネル3系統）／Poor（CAM）**の音声を取得（p10）。
- ケースを分解し、新しいコネクターケースに交換してNTSBのHFR5-V golden chassisに接続し再読み出ししたところ、**4チャンネルすべて Excellent**（p13）：3つのパネルは各約120分、CAMは約180分。
- 残った問題：CAMと乗員チャンネルの間で時間ドリフトが非線形。狭帯域チャンネルではランダムにパケットが欠落。
- **音声、元ファイル、中間ファイルはすべてCAACに返却。NTSBが保管したのは写真、スキャン、顕微鏡画像のみで、音声は保管していない。**

### 3.2 FDR（飛行記録装置、Honeywell HFR5-D、P/N 980-4750-009、S/N FDR-02952）

- 毎秒512個の12-bitワード。512ワードのブロックは1秒、1 subframeに相当し、同期語で1–4を識別する。
- 4月4日に受領。通常の読み出しは失敗し、イメージは全て0。U2フラッシュメモリチップの亀裂はパッケージ端からチップ中心まで貫通。データチップU1–U6のうち6個を取り外して直接読み出し、**U2は読み取り不能**、残る5個は読み出しに成功。
- U2の代わりに全FFのダミーファイルを使ってDLUを作成。事故区間がデータストリームの途中にあったため、手作業で末尾に並べ替えた。
- データはチップごとのストライプ状に書き込まれ、各チップ約1.3秒分、すなわち**有効データ6.5秒 + 欠測1.3秒**。ソフトウェアが8 subframeごとに誤って4個を補完し、約4秒の偽欠測を作ったため、境界を手作業で再整列。
- **時間精度を確保したのは最後の12分のみ**。その前の飛行の着陸／地上走行部分は補正。
- 1,000を超えるパラメータのうち約150個を検証。NTSB報告書の付録Bに153個のパラメータを掲載。
- データは高度約26,000 ftで停止（実際の最終有効点は25,389 ft）。理由は両エンジンのN2が発電機切離し点より低下したため。FDRにはバッテリーなし。CVRにはバッテリーがあり、少なくともあと10分録音できた。
- **事故経過に触れる唯一の段落（p23）**：高度29,000 ftで巡航中、両エンジンの燃料コントロールスイッチが RUN から CUTOFF に移り、その後エンジン回転数が低下した。

### 3.3 報告書の範囲

報告書は記録装置の修理、読み出し、引き渡しのみを扱い、分析も結論も示さない。署名はp24、p25–27はFDR曲線、p28–33は付録。**これは事故調査報告書ではない。**

## 5. ARINC 717 デコードと2便のプロファイル

### 5.1 デコード方法と較正

- ARINC 717：毎秒512個の12-bitワード、512ワードのブロックは1秒。同期語は0x247／0x5B8／0xA47／0xDB8の4秒周期、0xFFFは無効値。
- **ブロック内構成 = 16 minor frame × 32 word**。各パラメータは特定のminor-frame位相に固定され、未知数はスロット番号k（0–31）のみ。
- 時刻整合：**T0 = 43.000秒**（ブロックi ↔ 288,243.0+i。ブロック内の第mf minor frameにmf/16秒を加え、各wordにk/512秒を加える）。**NTSB行番号`640+16i`に合わせて1秒欠測3か所を無視すると、3秒のドリフトが生じる。再検証の結果、T0=43.000秒を採用した。**8 Hzで逐次残差を照合すると、T0=43.0の場合、Roll/Pitch残差のp90は0.178°から0.003°（量子化段差）に低下。ブロック長は**1.000秒**（U2欠測周期8ブロック = 8秒。B=1.0195では全区間の高度RMSが12,980 ftとなり棄却）。
- 高度：再適合した結果 **31.807 ft/count**。旧式の `raw×32.08+99` は系統的に126.6 ft高い（physics適合では125.6 ft。差1 ftは適合窓による）。補正後の巡航高度29,102 ft = FL291、最終値25,389 ft。レーダーの06:20:50時点の8,870 mとの差は0.3 ft。32 ftの量子化は物理的限界であり、32 ft未満の差を実値と解釈しない。
- 検証済み：原サンプルとの照合ではIASの中央値差0.00 kt、EGT 0、N1 0、**N2はbit-exact**。roll／pitch／wheelのp95 < 2°。デコードしたチャンネル位置とタイムスタンプの逆算は **31/31で一致**（個々のサンプルが時刻格子に落ちる残差中央値1.9e-5秒）。
- **最終デコードは32チャンネル**で、追加された項目はRoll_Rate、Accel_Lat/Long、Eng2_EGT/FF/N1、HydB。31チャンネルを解読し、Flapは未解読。補助翼スケールは**17.309／17.539**、方向舵は**17.844**。昇降舵／操縦桿はほぼ不変。残差中央値：補助翼 **0.0138／0.0117°**（旧校正より176倍／245倍改善）、昇降舵0.00065／0.00106°（3.3倍）、操縦桿0.00152／0.00581°（5.3倍）、方向舵0.0282°（3倍）、ロール率0.0093°/s。
- **Accel Lat/Longは解読済み**：スケール1964.4／1964.6 counts/g、残差5e-5／3e-4 g（出力精度による）、信頼度はmedium（±5%）。未解読：Oil Press/Temp、Flap（8秒周期の方形波状アーティファクト）。Stab Trimは165列に含まれない。前便のブロックから絶対時刻への独立した根拠がなく、絶対時刻の対応付けは確立できない。
- **独立検証**：**31/31チャンネルを再現**、補助翼17.309／17.539は成立。方向舵17.844は10–15%低い可能性（量子化レベルから逆算すると約15.4）。高度下降区間の量子化中央値は32.5 ft（巡航時の2.1 ftではない）。前便部分の負時刻区間には全ゼロのブロック7個／破損ブロック3個があるが、事故区間に影響しない（735/735ブロックが事故便のARINC 717データと一致）。Elevator_Rの補正オフセットの符号は修正済み。
- **8 Hzでの再検証**：操縦輪P2P **105.5°**（全区間で右操縦輪入力はなく、左入力と戻しのみ）。補助翼L/R P2P **19.8／21.8°**。ロール率P2P **48.8°/s**（slot 9／odd、raw/15.992、残差0.0093）。操縦桿8.7°、昇降舵7.7°、方向舵3.1°。
- 入力パターンは**左へほぼいっぱいに繰り返し操作し、戻す**もの：719／725–726／729–730では−99…−102°、723／728では−26…−9°まで戻す。主周波数は約0.09–0.10 Hzで、エネルギーの約19%は0.7–1.5 Hzの急速修正。操縦輪→補助翼の遅れ46 ms（r=−0.993）、補助翼→ロール率0.56秒（r=−0.972）、ロール角はロール率から89.2°遅れる（積分器）。

## 10. 限界と結論

- 証拠から確認できること：燃料コントロールスイッチが切り替わり、正常に作動していた操縦系統のもとで操縦輪が左方向に操作された（−19°～−102°を反復し、一定の最大左入力ではない）。約1.45回転の左ロールとピッチ−36°の急降下に入り、発電機切離しによりFDRが停止。レーダーは毎分21,600 ftの降下を記録した。
- 確認できないこと：誰が、なぜ、意図的だったか。FDRだけでは意図的操作、操縦不能、争い、共通原因故障を判別できない。重要な手掛かりとなるCVRは中国側が保有している。
- 公式見解の状況：調査はCAACが主導。2026-04の公開時点で最終報告書は公表されていない。2024-03-21のメールにも “since a final report has yet to be issued” と記載。
- 737NGの燃料コントロールスイッチには、スイッチを動かす際に引き上げる必要があるデテントスロット（detent slot）があるとFAA SAIB NM-18-33が説明している。ただし**同じSAIBの主題は、スロットが故障すると引き上げなくてもスイッチが動く可能性**である。そのため「通常は引き上げ操作が必要」という事実を「人為的でなければ動かない」という絶対的主張の根拠にしてはならない。設計背景としてのみ扱う。
- **感度分析**：主要結論10件のうち5件は頑健、4件は中程度、1件は脆弱。最も頑健なのは両エンジンの同時停止（離散パラメータに依存しない）、油圧／火災警報／両発対称、および燃料コントロールスイッチの切替（連続するCUTOFFを原サンプルデータで16件確認し、エンジン出力低下開始でも二重に裏付け）。最も脆弱なのは**衝突地点の幾何**であり、「左へ36°旋回 + 機首を起こす」という推定全体は公開資料外のCAAC初報地点に依存する。±5 kmは約±18秒に相当し、その地点を除けば純外挿の06:22:12–19に戻る。方向舵ペダル、累積ロール、操縦入力が誰によるものかは「中程度」：方向性は頑健だが、詳細な数値や「人が操作した」との帰属はFDRだけでは証明できない。
- 引用時の注意：「約26,000 ft」を測定値として使わない。06:30を衝突時刻としない。前便ARINC 717データの絶対時刻を確定値として使わない。方向舵角パラメータを「方向舵正常」の証拠にしない。06:21:25–35のレーダー航跡を実際の旋回として扱わない。
