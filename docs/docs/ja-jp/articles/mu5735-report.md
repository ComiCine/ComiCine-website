# MU5735 / DCA22WA102 資料調査報告


::: tip 読み進め方

要約と主要な時系列から読む場合は、§0 要約 → §1 時系列 → §3 FDRイベント → §4 ARINC 717デコード → §5 レーダー・物理・衝突 → §8 矛盾 → §9 限界と結論の順。技術的詳細は§3–§6、調査経緯は§7を参照。全章はページ内目次に表示される。

:::

## 0. 要約

2022-03-21、中国東方航空 MU5735便（B-737-800、B-1791、昆明 ZPPP → 広州 ZGGG）が広西チワン族自治区梧州市内に墜落し、乗客123人、乗員9人の全員が死亡した。事故調査は附属書13に基づき CAAC が主導し、NTSB が協力した。事故から4年後の2026年4月、NTSBは49 U.S.C. §1114(f) に基づき、1,959ページの記録、FDR表2点、FDR原ファイル3点を公開した。

::: info 1分でたどる経過

高度29,103 ftで巡航 → FDRの`Eng1 Cutoff SW`／`Eng2 Cutoff SW`フィールドが同一の1秒サンプリング窓内にRUNからCUTOFFへ変化 → 約1.8秒後、記録された`Left Control Wheel Position`は−28°。その後の記録値は、大きな左偏向とより中立に近い位置との間で繰り返し変化し、機体は左ロールを継続 → 左ロール約1.45回転、ピッチ姿勢は−35.86°に到達 → 両エンジンのN2がgenerator cutoff speedを下回り、航空機の発電機からの電力を失ったFDRは高度25,389 ftで記録を終了（FDRにバッテリー予備電源なし） → レーダーは毎分21,600 ftの降下を記録 → 06:21:40が最終実測点、衝突は約06:22:30。NTSB報告書は事故がCVRに記録され、4チャンネルすべてがExcellent評価だったとする。音声はCAACに返却され、今回のFOIA公開資料には含まれない。

:::

**資料が裏付ける事実関係：**

1. 高度29,103 ftで巡航中、**FDRの生データフィールド`Eng1 Cutoff SW`／`Eng2 Cutoff SW`が同一の1秒サンプリング窓内にRUNからCUTOFFへ変化**した。その後、N2は92.4%から49.9%（Eng 1）／52.5%（Eng 2）へ単調に低下し、N1は83.5%から25.6%／25.8%へ、EGTは623°Cから395／397°Cへ低下、燃料流量は0になった。**FDRが記録した`Left Engine Throttle Resolver Angle`と`Right Engine Throttle Resolver Angle`の値は全期間58.9–60.1°の範囲内だった。**
2. 燃料遮断から約1.8秒後、最初の有効サンプルの**`Left Control Wheel Position`は−28.1°**。その後は−19°～−102°の範囲で反復し、最大−101.95°、中央値は約−47°。記録された補助翼位置パラメータの最大偏向は約+17.8°／−18.4°。**ロールは同じ左方向に継続し、16.3秒間で累積約−528°～−540°（約1.45–1.50回転）、平均−32 ± 2°/s。ピッチ姿勢は+2.46°から−35.86°へ、IASは265 ktから339.75 ktへ、高度は29,103 ftから25,389 ftへ変化した。**
3. FDR記録の油圧はA 2,960–3,004 psi、B 2,972–3,016 psi。補助翼、昇降舵、操縦輪、操縦桿の各パラメータは記録区間に応答した。有効データでは両エンジンの火災警報はNO FIREで、両エンジンは同期して出力が低下し、片側が先に故障した形跡はない。これらは該当パラメータの応答を示すが、機体の全システムが正常だったことまでは示さない。
4. **両エンジンのN2がgenerator cutoff speedを下回った後、航空機の発電機から電力を得られず、バッテリー予備電源のないFDRは高度約25,389 ftで停止した。**N2のしきい値は約49%（48.6–49.9%、**推定**）、時刻は約06:21:06–07Z。レーダーの最終実測点は06:21:40Z、高度3,380 mであり、記録停止後も機体は約4,300 m降下した。
5. **CVRの4チャンネルはすべて Excellent**（音声パネル3系統は各約120分、CAMは約180分）。NTSBはCVRを受領して自らデータを読み出し、音声一式をCAACに返却した。FOIA回答書（`NTSB_response_to_FOIA_request_on_China_Eastern_Airlines_Flight_MU5735_alternative_version.pdf`、p.3）は、請求対象のCVRデータをSafety Boardが保有していないと記す。一方、記録器報告書は写真、スキャン、顕微鏡画像をNTSBが保持したと記す。**今回の公開資料には音声も書き起こしも含まれない。**
6. **2026-04の公開時点で、最終報告書は公表されていなかった。**第8巻のメールでは2024-03-21時点でも報告書の予定を問い合わせている。CAACの実質的な返信部分は(b)(5)で黒塗りされ、閲覧できる部分は謝意とビデオ会議の提案にとどまるため、予定について回答があったかは公開内容から判断できない。書簡には “since a final report has yet to be issued” と記されている。2024-03-20のCAAC二周年発表は、離陸前に航空機システム、機体構造、エンジン等の故障・異常は確認されなかったと述べるが、原因に関する結論や報告書の予定は示していない。

::: warning 証拠の限界

現有資料では、誰または何が記録値を変化させたのか、理由は何か、意図的だったかどうかを判定できない。NTSB報告書は両エンジンのfuel switchesがRUNからCUTOFFへ移動したと記述しており、対応するFDR項目は`Left Engine Cutoff Switch`と`Right Engine Cutoff Switch`である。FDRだけでは意図的操作、操縦不能、争い、機械的／電気的な共通原因故障を区別できない。CVR音声はCAACに返却された。事故原因を認定する権限を持つ機関はCAACである。

:::

## 1. 時系列（絶対時刻と範囲）

### 1.1 時刻基準

- CAAC／ATCの時刻は北京時間（UTC+8）、ACARSはUTC、FOIAメールは米東部夏時間（EDT、UTC−4）。
- FDR の `Time (sec)` は記録装置内部のカウンター（288,200–288,978秒）であり、時計時刻ではない。記録末尾とレーダー情報を使って逆算する。
- **ARINC 717データのブロック長は1.000秒／ブロックと判定**（U2の欠測周期8ブロック = NTSBの8秒、全区間の高度適合はB=1.0、B=1.0195ではRMS 12,980 ft）。前便の着陸記録を含むデータの一部は例外で時間軸が1.385倍に引き延ばされているため、絶対時刻の照合には使えない。

## 2. NTSB Cockpit Voice and Flight Data Recorder Combined Download Report（33ページ、2022-07-01；`FOIA Release Records - DCA22WA102 (1).pdf`に収録）

### 2.1 CVR（操縦室用音声記録装置、Honeywell HFR5-V、P/N 980-6032-001、S/N CVR-04014）

- 3月23日に発見。衝突による損傷が激しく、中国側は北京で代替ケースを使って複数回読み出しを試みたが失敗。
- NTSBが3月28日にCVRデータを受領。Playback32で4つの音声トラックを復号したが **unintelligible / unusable（判読不能／使用不能）**（p5）。
- 顕微鏡検査：コネクターのはんだパッド破断、ピン変形、グラウンド層断裂。ケースを開けるとさらに多くのピンが押しつぶされていた。製造時点ですでに電源フィルター用コンデンサー1個のはんだが外れていた。
- コネクター修理後、DLDRチップイメージとPlayback32を使い、**Fair（音声パネル3系統）／Poor（CAM）**の音声を取得（p10）。
- ケースを分解し、新しいコネクターケースに交換してNTSBのHFR5-V golden chassisに接続し再読み出ししたところ、**4チャンネルすべて Excellent**（p13）：3つのパネルは各約120分、CAMは約180分。
- 残った問題：CAMと乗員チャンネルの間で時間ドリフトが非線形。狭帯域チャンネルではランダムにパケットが欠落。
- **音声、元ファイル、中間ファイルはすべてCAACに返却。NTSBが保管したのは写真、スキャン、顕微鏡画像のみで、音声は保管していない。**

### 2.2 FDR（飛行記録装置、Honeywell HFR5-D、P/N 980-4750-009、S/N FDR-02952）

- 毎秒512個の12-bitワード。512ワードのブロックは1秒、1 subframeに相当し、同期語で1–4を識別する。
- 4月4日に受領。通常の読み出しは失敗し、イメージは全て0。U2フラッシュメモリチップの亀裂はパッケージ端からチップ中心まで貫通。データチップU1–U6のうち6個を取り外して直接読み出し、**U2は読み取り不能**、残る5個は読み出しに成功。
- U2の代わりに全FFのダミーファイルを使ってDLUを作成。事故区間がデータストリームの途中にあったため、手作業で末尾に並べ替えた。
- データはチップごとのストライプ状に書き込まれ、各チップ約1.3秒分、すなわち**有効データ6.5秒 + 欠測1.3秒**。ソフトウェアが8 subframeごとに誤って4個を補完し、約4秒の偽欠測を作ったため、境界を手作業で再整列。
- **時間精度を確保したのは最後の12分のみ**。その前の飛行の着陸／地上走行部分は補正。
- データは高度約26,000 ftで停止（実際の最終有効点は25,389 ft）。両エンジンのN2がgenerator cutoff speedを下回り、航空機の発電機から電力を得られなくなると、バッテリー予備電源のないFDRは停止する。NTSB報告書によると、CVRは航空機の発電機を喪失した後も少なくとも10分録音を継続できる。
- **事故経過に触れる唯一の段落（p23）**：高度29,000 ftで巡航中、両エンジンの燃料コントロールスイッチが RUN から CUTOFF に移り、その後エンジン回転数が低下した。

### 2.3 報告書の範囲

報告書は記録装置の修理、読み出し、引き渡しのみを扱い、分析も結論も示さない。署名はp24、p25–27はFDR曲線、p28–33は付録。**これは事故調査報告書ではない。**

### 3.2 エンジン

- N1は83.5 → 25.6／25.8%、N2は92.4 → 49.9／52.5%、EGTは623 → 395／397°C。FFは片エンジンあたり2,608 → 0（途中の304 → 1,056という非物理的な再上昇は再構成上のアーティファクトで、実際の燃料流量として扱わない）。
- **FDRが記録した`Left Engine Throttle Resolver Angle`と`Right Engine Throttle Resolver Angle`の値は全期間58.9–60.1°の範囲内だった**。NTSB報告書は “the fuel switches on both engines moved from the run position to the cutoff position” と記述している。
- 両エンジンは同期して出力低下し、片側エンジンが先に故障した兆候はない。有効データに火災警報はない（唯一の FIRE は最終のフルスケール異常フレーム）。

### 3.3 記録された操縦輪位置と機体姿勢

- 記録された`Left Control Wheel Position`：+3.5° → 最初の有効値−28.1° → 最大 **−101.95°**。イベント区間の**中央値は約−47°**で、サンプルのわずか**18%**が−90°以下。記録値は−19°～−102°の間で反復しており、**左いっぱいに固定されてはいない。**

### 3.4 データ品質

- FDR生データの`Eng1 Cutoff SW`／`Eng2 Cutoff SW`はNTSB検証パラメータ一覧の`Left Engine Cutoff Switch`／`Right Engine Cutoff Switch`に対応する。`Ctrl Whl Pos-L`は`Left Control Wheel Position`に対応し、スロットル角度の生データフィールドは`Eng1 TRA`／`Eng2 TRA`である。

## 4. ARINC 717 デコードと2便のプロファイル

### 4.1 デコード方法と較正

ARINC 717の元ファイル：`DCA22WA102-Final12minutes.upk`、`Last2Flights(final).upk`、`PreviousLanding+LastFlight_PartiallyCorrected(AsOf220414).upk`。

- ARINC 717：毎秒512個の12-bitワード、512ワードのブロックは1秒。同期語は0x247／0x5B8／0xA47／0xDB8の4秒周期、0xFFFは無効値。
- **ブロック内構成 = 16 minor frame × 32 word**。各パラメータは特定のminor-frame位相に固定され、未知数はスロット番号k（0–31）のみ。
- 時刻整合：**T0 = 43.000秒**（ブロックi ↔ 288,243.0+i。ブロック内の第mf minor frameにmf/16秒を加え、各wordにk/512秒を加える）。**NTSB行番号`640+16i`に合わせて1秒欠測3か所を無視すると、3秒のドリフトが生じる。再検証の結果、T0=43.000秒を採用した。**8 Hzで逐次残差を照合すると、T0=43.0の場合、Roll/Pitch残差のp90は0.178°から0.003°（量子化段差）に低下。ブロック長は**1.000秒**（U2欠測周期8ブロック = 8秒。B=1.0195では全区間の高度RMSが12,980 ftとなり棄却）。
- 高度：再適合した結果 **31.807 ft/count**。旧式の `raw×32.08+99` は系統的に126.6 ft高い（physics適合では125.6 ft。差1 ftは適合窓による）。補正後の巡航高度29,102 ft = FL291、最終値25,389 ft。レーダーの06:20:50時点の8,870 mとの差は0.3 ft。32 ftの量子化は物理的限界であり、32 ft未満の差を実値と解釈しない。
- 検証済み：原サンプルとの照合ではIASの中央値差0.00 kt、EGT 0、N1 0、**N2はbit-exact**。roll／pitch／wheelのp95 < 2°。デコードしたチャンネル位置とタイムスタンプの逆算は **31/31で一致**（個々のサンプルが時刻格子に落ちる残差中央値1.9e-5秒）。
- **最終デコードは32チャンネル**で、追加された項目はRoll_Rate、Accel_Lat/Long、Eng2_EGT/FF/N1、HydB。31チャンネルを解読し、Flapは未解読。補助翼スケールは**17.309／17.539**、方向舵は**17.844**。昇降舵／操縦桿はほぼ不変。残差中央値：補助翼 **0.0138／0.0117°**（旧校正より176倍／245倍改善）、昇降舵0.00065／0.00106°（3.3倍）、操縦桿0.00152／0.00581°（5.3倍）、方向舵0.0282°（3倍）、ロール率0.0093°/s。
- **Accel Lat/Longは解読済み**：スケール1964.4／1964.6 counts/g、残差5e-5／3e-4 g（出力精度による）、信頼度はmedium（±5%）。未解読：Oil Press/Temp、Flap（8秒周期の方形波状アーティファクト）。Stab Trimは165列に含まれない。前便のブロックから絶対時刻への独立した根拠がなく、絶対時刻の対応付けは確立できない。
- **独立検証**：**31/31チャンネルを再現**、補助翼17.309／17.539は成立。方向舵17.844は10–15%低い可能性（量子化レベルから逆算すると約15.4）。高度下降区間の量子化中央値は32.5 ft（巡航時の2.1 ftではない）。前便部分の負時刻区間には全ゼロのブロック7個／破損ブロック3個があるが、事故区間に影響しない（735/735ブロックが事故便のARINC 717データと一致）。Elevator_Rの補正オフセットの符号は修正済み。
- **8 Hzでの再検証**：`Left Control Wheel Position`系列のP2Pは **105.5°**（右操縦輪の系列は解析対象にしていない）。補助翼L/R P2P **19.8／21.8°**。ロール率P2P **48.8°/s**（slot 9／odd、raw/15.992、残差0.0093）。操縦桿8.7°、昇降舵7.7°、方向舵3.1°。
- 記録された`Left Control Wheel Position`の変化：719／725–726／729–730では−99…−102°、723／728では−26…−9°。主周波数は約0.09–0.10 Hzで、エネルギーの約19%は0.7–1.5 Hzの速い変化にある。操縦輪位置→補助翼の遅れ46 ms（r=−0.993）、補助翼→ロール率0.56秒（r=−0.972）、ロール角はロール率に対して89.2°遅れる（積分器）。

### 5.3 衝突

- 最終実測点06:21:40：高度3,380 m、速度1,010 km/h、航跡115°、終盤の垂直速度−86 m/s。
- 垂直方向のみの外挿では06:22:12–19、落下点は23.260°N 111.064°Eとなるが、これだけでは衝突地点を特定できない。[CAACの2022-04-20発表](http://www.caac.gov.cn/XXGK/XXGK/TZTG/202204/t20220420_212895.html)は **23°19′25.52″N 111°06′44.30″E** を主衝突地点としている。この地点はレーダー最終点から**14.90 km、方位078.7°**で、直線外挿点とは約**8.6 km**離れている。
- この衝突地点と整合する運動学シナリオの一つは、06:21:40以降に約36°左旋回し、平均降下率を約61 m/sに抑えること。簡略計算で必要な横加速度は約0.34 g（バンク約19°）。これは物理的に不可能ではないことを示すにとどまり、実際にこの軌跡を飛行した証拠ではない。

- 公開されている空港座標を使うと、06:21:40の最終実測点は梧州西江空港から約**17.5 km／方位049°**。座標ソース間の差が約0.6 kmあるため参考値。115°の外挿線と空港の最短距離は約**16.1 km**。通知表の「空港から5 km」はレーダー幾何に合わず、概略表現として扱う。

## 9. 限界と結論

- 証拠から確認できること：FDRの`Eng1 Cutoff SW`／`Eng2 Cutoff SW`がCUTOFFに変化し、記録された`Left Control Wheel Position`は−19°～−102°の間で反復した。関連パラメータも記録区間に応答したが、操縦系統全体の正常動作や、記録値の変化を誰または何が生じさせたかまでは示さない。機体は約1.45回転の左ロールとなり、ピッチ姿勢は−35.86°に達した。航空機の発電機からの電力を失ったFDRはバッテリー予備電源がなく停止し、レーダーは毎分21,600 ftの降下を記録した。
- 確認できないこと：誰または何が入力を生じさせたのか、理由、意図の有無。FDRだけでは意図的操作、操縦不能、争い、共通原因故障を判別できない。CVR音声はCAACに返却された。
- 公式見解の状況：調査はCAACが主導。2026-04の公開時点で最終報告書は公表されていない。2024-03-21のメールにも “since a final report has yet to be issued” と記載。
- 737NGの燃料コントロールスイッチには**locking feature（ロック機構）**がある。FAA [SAIB NM-18-33](https://drs.faa.gov/browse/excelExternalWindow/BBE820D0419DB3358625836600761396.0001)によると、ロック機構が係合している場合、スイッチを遷移させるときにパイロットはスイッチを持ち上げる必要がある。解除されている場合は持ち上げずに遷移させられる。この設計情報だけで意図しない移動が不可能とはいえない。
- **感度分析**：主要結論10件のうち5件は頑健、4件は中程度、1件は脆弱。比較的頑健なのは両エンジンの同期した出力低下、記録された油圧／火災警報パラメータ、燃料遮断スイッチ位置パラメータの変化（原サンプルデータに連続CUTOFFが16件あり、エンジン出力低下開始も独立に裏付ける）。最も脆弱なのは**衝突地点の幾何**であり、完全な「左へ36°旋回＋機首上げ」再構成はCAAC発表の主衝突地点に依存する。位置の不確かさ±5 kmは約±18秒に相当し、その地点を使わない場合は06:22:12–19の垂直外挿のみが残る。方向舵ペダル、累積ロール、記録値変化の帰属は中程度：方向は頑健だが、正確な値や誰または何が変化を生じさせたかはFDRだけでは特定できない。
- 引用時の注意：「約26,000 ft」を測定値として使わない。06:30を衝突時刻としない。前便ARINC 717データの絶対時刻を確定値として使わない。方向舵角パラメータを「方向舵正常」の証拠にしない。06:21:25–35のレーダー航跡を実際の旋回として扱わない。
