# MU5735 / DCA22WA102 資料調査・解析報告

## 0. 概要

2022-03-21、中国東方航空 MU5735便（B-737-800（ボーイング737-800型）、B-1791（航空機登録番号）、昆明 ZPPP（昆明長水国際空港） → 広州 ZGGG（広州白雲国際空港））が広西チワン族自治区梧州市内に墜落し、乗客123人、乗員9人の全員が死亡した。事故調査は附属書13に基づき CAAC（中国民用航空局）が主導し、NTSB（米国国家運輸安全委員会）が協力した。事故から4年後の2026年4月、NTSB（米国国家運輸安全委員会）は49 U.S.C.（米国法典） §1114(f) に基づき、1,959ページの記録、FDR（飛行記録装置）表2点、FDR（飛行記録装置）原ファイル3点を公開した。

### 事故経過の概要

高度29,103 ft（フィート）で巡航中、FDR（飛行記録装置）の`Eng1 Cutoff SW`（第1エンジン燃料遮断スイッチ状態）及び`Eng2 Cutoff SW`（第2エンジン燃料遮断スイッチ状態）は同一の1秒サンプリング窓内でRUN（運転）からCUTOFF（遮断）へ変化した。約1.8秒後、記録された`Left Control Wheel Position`（左操縦輪位置）は−28°を示した。その後、同位置は大きな左偏向と中立に近い位置との間で反復し、機体は左ロールを継続した。左ロールは約1.45回転、ピッチ姿勢は−35.86°に達した。両エンジンのN2（コア回転数）がgenerator cutoff speed（発電機遮断回転数）を下回り、航空機の発電機からの電力が失われた後、バッテリー予備電源のないFDR（飛行記録装置）は高度25,389 ft（フィート）で記録を終了した。レーダーは毎分21,600 ft（フィート）の降下を記録し、最終実測点は06:21:40、衝突時刻の推定中心は約06:22:30である。NTSB（米国国家運輸安全委員会）の記録器報告書は、事故の音声がCVR（操縦室音声記録装置）に記録され、4チャンネルすべてがExcellent（優秀）と評価されたと記載する。音声はCAAC（中国民用航空局）に返却され、今回のFOIA（米国情報公開法）公開資料には含まれない。

### 記録資料から確認された事項

1. 高度29,103 ft（フィート）で巡航中、**FDR（飛行記録装置）の生データフィールド`Eng1 Cutoff SW`（第1エンジン燃料遮断スイッチ状態）／`Eng2 Cutoff SW`（第2エンジン燃料遮断スイッチ状態）が同一の1秒サンプリング窓内にRUN（運転）からCUTOFF（遮断）へ変化**した。その後、N2（コア回転数）は92.4%から49.9%（Eng 1（第1エンジン））／52.5%（Eng 2（第2エンジン））へ単調に低下し、N1（ファン回転数）は83.5%から25.6%／25.8%へ、EGT（排気ガス温度）は623°C（摂氏度）から395／397°C（摂氏度）へ低下、燃料流量は0になった。**FDR（飛行記録装置）が記録した`Left Engine Throttle Resolver Angle`（左エンジンのスロットル・レゾルバ角）と`Right Engine Throttle Resolver Angle`（右エンジンのスロットル・レゾルバ角）の値は全期間58.9–60.1°の範囲内だった。**
2. 燃料遮断から約1.8秒後、最初の有効サンプルの**`Left Control Wheel Position`（左操縦輪位置）は−28.1°**。その後は−19°～−102°の範囲で反復し、最大−101.95°、中央値は約−47°。記録された補助翼位置パラメータの最大偏向は約+17.8°／−18.4°。**ロールは同じ左方向に継続し、16.3秒間で累積約−528°～−540°（約1.45–1.50回転）、平均−32 ± 2°/s（度/秒）。ピッチ姿勢は+2.46°から−35.86°へ、IAS（指示対気速度）は265 kt（ノット）から339.75 kt（ノット）へ、高度は29,103 ft（フィート）から25,389 ft（フィート）へ変化した。**
3. FDR（飛行記録装置）記録の油圧はA 2,960–3,004 psi（重量ポンド毎平方インチ）、B 2,972–3,016 psi（重量ポンド毎平方インチ）。補助翼、昇降舵、操縦輪、操縦桿の各パラメータは記録区間に応答した。有効データでは両エンジンの火災警報はNO FIRE（火災警報なし）で、両エンジンは同期して出力が低下し、片側が先に故障した形跡はない。ここに示す評価対象は、公開資料に記録された各パラメータである。
4. **両エンジンのN2（コア回転数）がgenerator cutoff speed（発電機遮断回転数）を下回った後、航空機の発電機から電力を得られず、バッテリー予備電源のないFDR（飛行記録装置）は高度約25,389 ft（フィート）で停止した。**N2（コア回転数）のしきい値は約49%（48.6–49.9%、**推定**）、時刻は約06:21:06–07Z（協定世界時を示す記号）。レーダーの最終実測点は06:21:40Z（協定世界時を示す記号）、高度3,380 m（メートル）であり、記録停止後も機体は約4,300 m（メートル）降下した。
5. **CVR（操縦室音声記録装置）の4チャンネルはすべて Excellent（優秀）**（音声パネル3系統は各約120分、CAM（操縦室エリアマイク）は約180分）。NTSB（米国国家運輸安全委員会）はCVR（操縦室音声記録装置）を受領して自らデータを読み出し、音声一式をCAAC（中国民用航空局）に返却した。FOIA（米国情報公開法）回答書（`NTSB_response_to_FOIA_request_on_China_Eastern_Airlines_Flight_MU5735_alternative_version.pdf`（米国国家運輸安全委員会によるMU5735情報公開請求への回答（代替版、PDF（ポータブル文書形式）））、p.3）は、請求対象のCVR（操縦室音声記録装置）データをSafety Board（米国国家運輸安全委員会）が保有していないと記す。一方、記録器報告書は写真、スキャン、顕微鏡画像をNTSB（米国国家運輸安全委員会）が保持したと記す。**今回の公開資料には音声も書き起こしも含まれない。**
6. **2026-04の公開時点で、最終報告書は公表されていなかった。**第8巻所収のメールでは、2024-03-21に報告書の予定が照会されている。CAAC（中国民用航空局）からの返信は一部が(b)(5)（米国情報公開法の第5号適用除外）で黒塗りされ、閲覧可能な部分には謝意とビデオ会議の提案が記録されている。報告書予定に関する実質的な回答部分は黒塗りである。書簡には “since a final report has yet to be issued”（最終報告書がまだ発行されていないため）と記されている。2024-03-20のCAAC（中国民用航空局）二周年発表は、離陸前に航空機システム、機体構造、エンジン等の故障・異常は確認されなかったと述べている。同発表に事故原因の結論又は報告書の予定は記載されていない。

- CAAC（中国民用航空局）／ATC（航空交通管制）の時刻は北京時間（UTC（協定世界時）+8）、ACARS（航空機通信アドレス・報告システム）はUTC（協定世界時）、FOIA（米国情報公開法）メールは米東部夏時間（EDT（米国東部夏時間）、UTC（協定世界時）−4）。

## 2. 記録器報告書（33頁、2022-07-01）

NTSB（米国国家運輸安全委員会）原文書名：`Cockpit Voice and Flight Data Recorder Combined Download Report`（操縦室音声記録装置及び飛行記録装置の統合読出報告書）。`FOIA Release Records - DCA22WA102 (1).pdf`（情報公開記録第1巻（PDF（ポータブル文書形式）））に収録。

### 2.1 CVR（操縦室用音声記録装置、Honeywell（ハネウェル） HFR5-V、P/N（部品番号） 980-6032-001、S/N（製造番号） CVR-04014）

- 3月23日に発見。衝突による損傷が激しく、中国側は北京で代替ケースを使って複数回読み出しを試みたが失敗。
- NTSB（米国国家運輸安全委員会）が3月28日にCVR（操縦室音声記録装置）データを受領。Playback32（操縦室音声記録装置の再生ソフトウェア）で4つの音声トラックを復号したが **unintelligible（聴取不能） / unusable（使用不能）**（p5）。
- 顕微鏡検査：コネクターのはんだパッド破断、ピン変形、グラウンド層断裂。ケースを開けるとさらに多くのピンが押しつぶされていた。製造時点ですでに電源フィルター用コンデンサー1個のはんだが外れていた。
- コネクター修理後、DLDR（チップ直接読出しツール）チップイメージとPlayback32（操縦室音声記録装置の再生ソフトウェア）を使い、**Fair（可；音声品質評価、音声パネル3系統）／Poor（不良；音声品質評価、CAM（操縦室エリアマイク））**の音声を取得（p10）。
- ケースを分解し、新しいコネクターケースに交換してNTSB（米国国家運輸安全委員会）のHFR5-V golden chassis（基準シャーシ）に接続し再読み出ししたところ、**4チャンネルすべて Excellent（優秀）**（p13）：3つのパネルは各約120分、CAM（操縦室エリアマイク）は約180分。
- 記録上の留意事項：CAM（操縦室エリアマイク）と乗員チャンネルの時間ドリフトは非線形である。狭帯域チャンネルではパケットが断続的に欠落した。
- **音声、元ファイル、中間ファイルはすべてCAAC（中国民用航空局）に返却。NTSB（米国国家運輸安全委員会）が保管したのは写真、スキャン、顕微鏡画像のみで、音声は保管していない。**

### 2.2 FDR（飛行記録装置）（Honeywell（ハネウェル） HFR5-D、P/N（部品番号） 980-4750-009、S/N（製造番号） FDR-02952）

- 毎秒512個の12-bit（ビット）ワード。512ワードのブロックは1秒、1 subframe（サブフレーム）に相当し、同期語で1–4を識別する。
- 4月4日に受領。通常の読み出しは失敗し、イメージは全て0。U2フラッシュメモリチップの亀裂はパッケージ端からチップ中心まで貫通。データチップU1–U6のうち6個を取り外して直接読み出し、**U2は読み取り不能**、残る5個は読み出しに成功。
- U2の代わりに全FF（16進数の0xFF、二進数の全1）で構成したダミーファイルを使ってDLU（飛行データファイル；原報告では略語を展開していない）を作成。事故区間がデータストリームの途中にあったため、手作業で末尾に並べ替えた。
- データはチップごとのストライプ状に書き込まれ、各チップ約1.3秒分、すなわち**有効データ6.5秒 + 欠測1.3秒**。ソフトウェアが8 subframe（サブフレーム）ごとに誤って4個を補完し、約4秒の偽欠測を作ったため、境界を手作業で再整列。
- **時間精度を確保したのは最後の12分のみ**。その前の飛行の着陸／地上走行部分は補正。
- データは高度約26,000 ft（フィート）で停止（実際の最終有効点は25,389 ft（フィート））。両エンジンのN2（コア回転数）がgenerator cutoff speed（発電機遮断回転数）を下回り、航空機の発電機から電力を得られなくなると、バッテリー予備電源のないFDR（飛行記録装置）は停止する。NTSB（米国国家運輸安全委員会）報告書によると、CVR（操縦室音声記録装置）は航空機の発電機を喪失した後も少なくとも10分録音を継続できる。
- **事故経過に触れる唯一の段落（p23）**：高度29,000 ft（フィート）で巡航中、両エンジンの燃料コントロールスイッチが RUN（運転）から CUTOFF（遮断）に移り、その後エンジン回転数が低下した。

### 2.3 報告書の記載範囲

### 4.1 復号方法及び較正

- ARINC 717（飛行データ記録規格）：毎秒512個の12-bit（ビット）ワード、512ワードのブロックは1秒。同期語は0x247／0x5B8／0xA47／0xDB8の4秒周期、0xFFFは無効値。
