# MU5735 / DCA22WA102 資料調査報告


::: tip 読み進め方

## 0. 要約

2022-03-21、中国東方航空 MU5735便（B-737-800、B-1791、昆明 ZPPP → 広州 ZGGG）が広西チワン族自治区梧州市内に墜落し、乗客123人、乗員9人の全員が死亡した。事故調査は附属書13に基づき CAAC（中国民用航空局）が主導し、NTSB（米国国家運輸安全委員会）が協力した。事故から4年後の2026年4月、NTSB（米国国家運輸安全委員会）は49 U.S.C.（米国法典） §1114(f) に基づき、1,959ページの記録、FDR（飛行記録装置）表2点、FDR（飛行記録装置）原ファイル3点を公開した。

::: info 1分でたどる経過

高度29,103 ft（フィート）で巡航 → FDR（飛行記録装置）の`Eng1 Cutoff SW`（第1エンジン燃料遮断スイッチ状態）／`Eng2 Cutoff SW`（第2エンジン燃料遮断スイッチ状態）フィールドが同一の1秒サンプリング窓内にRUN（運転）からCUTOFF（遮断）へ変化 → 約1.8秒後、記録された`Left Control Wheel Position`（左操縦輪位置）は−28°。その後の記録値は、大きな左偏向とより中立に近い位置との間で繰り返し変化し、機体は左ロールを継続 → 左ロール約1.45回転、ピッチ姿勢は−35.86°に到達 → 両エンジンのN2（コア回転数）がgenerator cutoff speed（発電機遮断回転数）を下回り、航空機の発電機からの電力を失ったFDR（飛行記録装置）は高度25,389 ft（フィート）で記録を終了（FDR（飛行記録装置）にバッテリー予備電源なし） → レーダーは毎分21,600 ft（フィート）の降下を記録 → 06:21:40が最終実測点、衝突は約06:22:30。NTSB（米国国家運輸安全委員会）報告書は事故がCVR（操縦室音声記録装置）に記録され、4チャンネルすべてがExcellent（優秀）評価だったとする。音声はCAAC（中国民用航空局）に返却され、今回のFOIA（米国情報公開法）公開資料には含まれない。

:::

**資料が裏付ける事実関係：**

1. 高度29,103 ft（フィート）で巡航中、**FDR（飛行記録装置）の生データフィールド`Eng1 Cutoff SW`（第1エンジン燃料遮断スイッチ状態）／`Eng2 Cutoff SW`（第2エンジン燃料遮断スイッチ状態）が同一の1秒サンプリング窓内にRUN（運転）からCUTOFF（遮断）へ変化**した。その後、N2（コア回転数）は92.4%から49.9%（Eng 1（第1エンジン））／52.5%（Eng 2（第2エンジン））へ単調に低下し、N1（ファン回転数）は83.5%から25.6%／25.8%へ、EGT（排気ガス温度）は623°C（摂氏度）から395／397°C（摂氏度）へ低下、燃料流量は0になった。**FDR（飛行記録装置）が記録した`Left Engine Throttle Resolver Angle`（左エンジンのスロットル・レゾルバ角）と`Right Engine Throttle Resolver Angle`（右エンジンのスロットル・レゾルバ角）の値は全期間58.9–60.1°の範囲内だった。**
2. 燃料遮断から約1.8秒後、最初の有効サンプルの**`Left Control Wheel Position`（左操縦輪位置）は−28.1°**。その後は−19°～−102°の範囲で反復し、最大−101.95°、中央値は約−47°。記録された補助翼位置パラメータの最大偏向は約+17.8°／−18.4°。**ロールは同じ左方向に継続し、16.3秒間で累積約−528°～−540°（約1.45–1.50回転）、平均−32 ± 2°/s（度/秒）。ピッチ姿勢は+2.46°から−35.86°へ、IAS（指示対気速度）は265 kt（ノット）から339.75 kt（ノット）へ、高度は29,103 ft（フィート）から25,389 ft（フィート）へ変化した。**
3. FDR（飛行記録装置）記録の油圧はA 2,960–3,004 psi（重量ポンド毎平方インチ）、B 2,972–3,016 psi（重量ポンド毎平方インチ）。補助翼、昇降舵、操縦輪、操縦桿の各パラメータは記録区間に応答した。有効データでは両エンジンの火災警報はNO FIRE（火災警報なし）で、両エンジンは同期して出力が低下し、片側が先に故障した形跡はない。これらは該当パラメータの応答を示すが、機体の全システムが正常だったことまでは示さない。
4. **両エンジンのN2（コア回転数）がgenerator cutoff speed（発電機遮断回転数）を下回った後、航空機の発電機から電力を得られず、バッテリー予備電源のないFDR（飛行記録装置）は高度約25,389 ft（フィート）で停止した。**N2（コア回転数）のしきい値は約49%（48.6–49.9%、**推定**）、時刻は約06:21:06–07Z（協定世界時を示す記号）。レーダーの最終実測点は06:21:40Z、高度3,380 m（メートル）であり、記録停止後も機体は約4,300 m（メートル）降下した。
5. **CVR（操縦室音声記録装置）の4チャンネルはすべて Excellent（優秀）**（音声パネル3系統は各約120分、CAM（操縦室エリアマイク）は約180分）。NTSB（米国国家運輸安全委員会）はCVR（操縦室音声記録装置）を受領して自らデータを読み出し、音声一式をCAAC（中国民用航空局）に返却した。FOIA（米国情報公開法）回答書（`NTSB_response_to_FOIA_request_on_China_Eastern_Airlines_Flight_MU5735_alternative_version.pdf`（米国国家運輸安全委員会によるMU5735情報公開請求への回答（代替版、PDF（ポータブル文書形式）））、p.3）は、請求対象のCVR（操縦室音声記録装置）データをSafety Boardが保有していないと記す。一方、記録器報告書は写真、スキャン、顕微鏡画像をNTSB（米国国家運輸安全委員会）が保持したと記す。**今回の公開資料には音声も書き起こしも含まれない。**
6. **2026-04の公開時点で、最終報告書は公表されていなかった。**第8巻のメールでは2024-03-21時点でも報告書の予定を問い合わせている。CAAC（中国民用航空局）の実質的な返信部分は(b)(5)で黒塗りされ、閲覧できる部分は謝意とビデオ会議の提案にとどまるため、予定について回答があったかは公開内容から判断できない。書簡には “since a final report has yet to be issued”（最終報告書がまだ発行されていないため）と記されている。2024-03-20のCAAC（中国民用航空局）二周年発表は、離陸前に航空機システム、機体構造、エンジン等の故障・異常は確認されなかったと述べるが、原因に関する結論や報告書の予定は示していない。

## 2. NTSB（米国国家運輸安全委員会） Cockpit Voice and Flight Data Recorder Combined Download Report（操縦室音声記録装置と飛行記録装置の統合ダウンロード報告書）（33ページ、2022-07-01；`FOIA Release Records - DCA22WA102 (1).pdf`（情報公開記録第1巻（PDF（ポータブル文書形式）））に収録）

### 2.1 CVR（操縦室用音声記録装置、Honeywell（ハネウェル） HFR5-V、P/N（部品番号） 980-6032-001、S/N（製造番号） CVR-04014）

- 3月23日に発見。衝突による損傷が激しく、中国側は北京で代替ケースを使って複数回読み出しを試みたが失敗。
- NTSB（米国国家運輸安全委員会）が3月28日にCVR（操縦室音声記録装置）データを受領。Playback32（操縦室音声記録装置の再生ソフトウェア）で4つの音声トラックを復号したが **unintelligible（聴取不能） / unusable（使用不能）**（p5）。
- 顕微鏡検査：コネクターのはんだパッド破断、ピン変形、グラウンド層断裂。ケースを開けるとさらに多くのピンが押しつぶされていた。製造時点ですでに電源フィルター用コンデンサー1個のはんだが外れていた。
- コネクター修理後、DLDR（チップ直接読出しツール）チップイメージとPlayback32（操縦室音声記録装置の再生ソフトウェア）を使い、**Fair（可；音声品質評価、音声パネル3系統）／Poor（不良；音声品質評価、CAM（操縦室エリアマイク））**の音声を取得（p10）。
- ケースを分解し、新しいコネクターケースに交換してNTSB（米国国家運輸安全委員会）のHFR5-V golden chassis（基準シャーシ）に接続し再読み出ししたところ、**4チャンネルすべて Excellent（優秀）**（p13）：3つのパネルは各約120分、CAM（操縦室エリアマイク）は約180分。
- 残った問題：CAM（操縦室エリアマイク）と乗員チャンネルの間で時間ドリフトが非線形。狭帯域チャンネルではランダムにパケットが欠落。
- **音声、元ファイル、中間ファイルはすべてCAAC（中国民用航空局）に返却。NTSB（米国国家運輸安全委員会）が保管したのは写真、スキャン、顕微鏡画像のみで、音声は保管していない。**

### 2.2 FDR（飛行記録装置）（Honeywell（ハネウェル） HFR5-D、P/N（部品番号） 980-4750-009、S/N（製造番号） FDR-02952）

- 毎秒512個の12-bit（ビット）ワード。512ワードのブロックは1秒、1 subframe（サブフレーム）に相当し、同期語で1–4を識別する。
- 4月4日に受領。通常の読み出しは失敗し、イメージは全て0。U2フラッシュメモリチップの亀裂はパッケージ端からチップ中心まで貫通。データチップU1–U6のうち6個を取り外して直接読み出し、**U2は読み取り不能**、残る5個は読み出しに成功。
- U2の代わりに全FF（16進数の0xFF、二進数の全1）で構成したダミーファイルを使ってDLU（飛行データファイル；原報告では略語を展開していない）を作成。事故区間がデータストリームの途中にあったため、手作業で末尾に並べ替えた。
- データはチップごとのストライプ状に書き込まれ、各チップ約1.3秒分、すなわち**有効データ6.5秒 + 欠測1.3秒**。ソフトウェアが8 subframe（サブフレーム）ごとに誤って4個を補完し、約4秒の偽欠測を作ったため、境界を手作業で再整列。
- **時間精度を確保したのは最後の12分のみ**。その前の飛行の着陸／地上走行部分は補正。
- データは高度約26,000 ft（フィート）で停止（実際の最終有効点は25,389 ft（フィート））。両エンジンのN2（コア回転数）がgenerator cutoff speed（発電機遮断回転数）を下回り、航空機の発電機から電力を得られなくなると、バッテリー予備電源のないFDR（飛行記録装置）は停止する。NTSB（米国国家運輸安全委員会）報告書によると、CVR（操縦室音声記録装置）は航空機の発電機を喪失した後も少なくとも10分録音を継続できる。
- **事故経過に触れる唯一の段落（p23）**：高度29,000 ft（フィート）で巡航中、両エンジンの燃料コントロールスイッチが RUN（運転）から CUTOFF（遮断）に移り、その後エンジン回転数が低下した。

### 2.3 報告書の範囲

報告書は記録装置の修理、読み出し、引き渡しのみを扱い、分析も結論も示さない。署名はp24、p25–27はFDR（飛行記録装置）曲線、p28–33は付録。**これは事故調査報告書ではない。**

## 4. ARINC 717（飛行データ記録規格）デコードと2便のプロファイル

### 4.1 デコード方法と較正

ARINC 717（飛行データ記録規格）の元ファイル：`DCA22WA102-Final12minutes.upk`（DCA22WA102最終12分間の飛行データ解読ファイル）、`Last2Flights(final).upk`（直近2便の飛行データ解読ファイル（最終版））、`PreviousLanding+LastFlight_PartiallyCorrected(AsOf220414).upk`（前回着陸と最終便の部分補正飛行データ（2022-04-14時点））。

- ARINC 717（飛行データ記録規格）：毎秒512個の12-bit（ビット）ワード、512ワードのブロックは1秒。同期語は0x247／0x5B8／0xA47／0xDB8の4秒周期、0xFFFは無効値。
- **ブロック内構成 = 16 minor frame（マイナーフレーム） × 32 word（データ語）**。各パラメータは特定のminor-frame（マイナーフレーム）位相に固定され、未知数はスロット番号k（0–31）のみ。
- 時刻整合：**T0（時間ゼロ点） = 43.000秒**（ブロックi ↔ 288,243.0+i。ブロック内の第mf minor frame（マイナーフレーム）にmf/16秒を加え、各word（データ語）にk/512秒を加える）。**NTSB（米国国家運輸安全委員会）行番号`640+16i`に合わせて1秒欠測3か所を無視すると、3秒のドリフトが生じる。再検証の結果、T0（時間ゼロ点）=43.000秒を採用した。**8 Hz（ヘルツ）で逐次残差を照合すると、T0（時間ゼロ点）=43.0の場合、Roll（ロール）/Pitch（ピッチ）残差のp90（90パーセンタイル）は0.178°から0.003°（量子化段差）に低下。ブロック長は**1.000秒**（U2欠測周期8ブロック = 8秒。B=1.0195では全区間の高度RMS（二乗平均平方根）が12,980 ft（フィート）となり棄却）。
- 高度：再適合した結果 **31.807 ft/count（フィート／カウント値）**。旧式の `raw×32.08+99`（生データ値×32.08+99）は系統的に126.6 ft（フィート）高い（physics適合では125.6 ft（フィート）。差1 ft（フィート）は適合窓による）。補正後の巡航高度29,102 ft（フィート） = FL291（飛行高度層291）、最終値25,389 ft（フィート）。レーダーの06:20:50時点の8,870 m（メートル）との差は0.3 ft（フィート）。32 ft（フィート）の量子化は物理的限界であり、32 ft（フィート）未満の差を実値と解釈しない。
- 検証済み：原サンプルとの照合ではIAS（指示対気速度）の中央値差0.00 kt（ノット）、EGT（排気ガス温度） 0、N1（ファン回転数） 0、**N2（コア回転数）はbit（ビット）-exact**。roll（ロール）／pitch（ピッチ）／wheel（操縦輪）のp95（95パーセンタイル） < 2°。デコードしたチャンネル位置とタイムスタンプの逆算は **31/31で一致**（個々のサンプルが時刻格子に落ちる残差中央値1.9e-5秒）。

## 9. 限界と結論

- 証拠から確認できること：FDR（飛行記録装置）の`Eng1 Cutoff SW`（第1エンジン燃料遮断スイッチ状態）／`Eng2 Cutoff SW`（第2エンジン燃料遮断スイッチ状態）がCUTOFF（遮断）に変化し、記録された`Left Control Wheel Position`（左操縦輪位置）は−19°～−102°の間で反復した。関連パラメータも記録区間に応答したが、操縦系統全体の正常動作や、記録値の変化を誰または何が生じさせたかまでは示さない。機体は約1.45回転の左ロールとなり、ピッチ姿勢は−35.86°に達した。航空機の発電機からの電力を失ったFDR（飛行記録装置）はバッテリー予備電源がなく停止し、レーダーは毎分21,600 ft（フィート）の降下を記録した。
- 確認できないこと：誰または何が入力を生じさせたのか、理由、意図の有無。FDR（飛行記録装置）だけでは意図的操作、操縦不能、争い、共通原因故障を判別できない。CVR（操縦室音声記録装置）音声はCAAC（中国民用航空局）に返却された。
- 公式見解の状況：調査はCAAC（中国民用航空局）が主導。2026-04の公開時点で最終報告書は公表されていない。2024-03-21のメールにも “since a final report has yet to be issued”（最終報告書がまだ発行されていないため）と記載。
- 737NGの燃料コントロールスイッチには**locking feature（ロック機構）**がある。FAA（米国連邦航空局） [SAIB（特別耐空性情報通報） NM-18-33](https://drs.faa.gov/browse/excelExternalWindow/BBE820D0419DB3358625836600761396.0001)によると、ロック機構が係合している場合、スイッチを遷移させるときにパイロットはスイッチを持ち上げる必要がある。解除されている場合は持ち上げずに遷移させられる。この設計情報だけで意図しない移動が不可能とはいえない。
- **感度分析**：主要結論10件のうち5件は頑健、4件は中程度、1件は脆弱。比較的頑健なのは両エンジンの同期した出力低下、記録された油圧／火災警報パラメータ、燃料遮断スイッチ位置パラメータの変化（原サンプルデータに連続CUTOFF（遮断）が16件あり、エンジン出力低下開始も独立に裏付ける）。最も脆弱なのは**衝突地点の幾何**であり、完全な「左へ36°旋回＋機首上げ」再構成はCAAC（中国民用航空局）発表の主衝突地点に依存する。位置の不確かさ±5 km（キロメートル）は約±18秒に相当し、その地点を使わない場合は06:22:12–19の垂直外挿のみが残る。方向舵ペダル、累積ロール、記録値変化の帰属は中程度：方向は頑健だが、正確な値や誰または何が変化を生じさせたかはFDR（飛行記録装置）だけでは特定できない。
- 引用時の注意：「約26,000 ft（フィート）」を測定値として使わない。06:30を衝突時刻としない。前便ARINC 717（飛行データ記録規格）データの絶対時刻を確定値として使わない。方向舵角パラメータを「方向舵正常」の証拠にしない。06:21:25–35のレーダー航跡を実際の旋回として扱わない。
