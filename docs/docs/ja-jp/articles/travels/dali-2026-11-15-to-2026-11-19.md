## 11月16日｜洱海東岸 {#nov-16}

**ルート**：民宿 → 双廊古鎮 → 挖色埠頭 → 小普陀 → 文筆村 → 向陽村 → 民宿。

この日は洱海東岸を北から南へ巡ります。各スポット間は車で移動します。1台の車を終日利用すると途中で車を探す時間を減らせます。区間ごとに配車する方法もあります。

|---|---|---|---|
| 08:30〜09:30 | 民宿 | 朝食 | — |
| 09:30〜10:40 | 双廊へ | 向陽村を出発し、双廊古鎮の公共駐車場へ | 車で約45〜70分 |
| 10:40〜12:15 | 双廊古鎮 | 古鎮の路地から玉几橋周辺へ歩き、湖畔の遊歩道、商店、白族の民家が並ぶ地区を散策 | 徒歩 |
| 12:15〜13:20 | 双廊 | 昼食、休憩 | 徒歩 |

| 14:15〜15:25 | 海印村、小普陀 | 小普陀の対岸にある海印村へ行き、小普陀周辺の湖岸を散策 | 車で約10〜20分、その後徒歩 |

| 18:30〜20:00 | 向陽村、民宿 | 向陽村へ戻り、夕食後に民宿へ | 車で約10〜25分 |

### 立ち寄り先と食事

**双廊古鎮**：公共駐車場から古鎮に入り、玉几橋や湖畔の路地を中心に散策します。古鎮の公共エリアは無料です。昼食は玉几橋近くの**双廊文化大院海景餐庁（双廊文化大院海景餐厅）**がおすすめです。白族風の酸辣魚、野菜、雲南の家庭料理があります。

**挖色埠頭**：埠頭周辺の公共エリアを散策し、30〜45分ほど滞在します。ここから湖岸沿いに海印村へ向かいます。

**小普陀**：海印村近くの湖上にある小島です。この行程では岸の公共遊歩道を歩きます。周辺観光のために船を手配する必要はありません。

**文筆村**：村内には展望遊歩道、カフェ、休憩場所があります。夕方は村内で食事をするか、向陽村に戻って夕食を取ります。

**夕食**：向陽村では**民家苑**（向陽村六社1号）の銅鍋牛肉火鍋を選べます。民宿の近くで白族の家庭料理を食べる方法もあります。

### 交通と入場料

- 双廊古鎮、挖色埠頭周辺の公共エリア、小普陀の対岸、文筆村の公共の通りは**無料で散策**できます。
- 環海東路G348の一部区間は道路維持工事中で、車両が交互通行となる場合があります。大幅な遅れが出たら挖色埠頭の滞在を短縮し、双廊、小普陀、文筆村の順序を保ちます。
- 所要時間は行程作成時の目安です。当日のナビゲーションに従ってください。

[双廊景勝地情報](https://www.yndali.gov.cn/dlsrmzf/c106716/pc/content/1983786742782726144/content_1983786742782726144.html) · [道路工事のお知らせ](https://www.sohu.com/a/1003511850_120815119) · [民家苑の場所](https://www.amap.com/place/B0FFLJWH2X)

### 観光スポットと食事

**大理古城**：南門から入り、復興路、五華楼、人民路を順に巡ります。メインストリートと公共の路地は無料で入れます。古城には白族建築、工芸品店、地元の軽食や飲食店があります。

**龍龕埠頭**：洱海西岸の生態回廊の端にあります。湖畔の公共遊歩道を往復し、滞在時間に応じて歩く距離を調整します。生態回廊内は車両の通行が制限されているため、配車の乗降場所は外側の道路にします。

**昼食・夕食**：古城では涼鶏米線、餌絲、乳扇、汽鍋鶏などを楽しめます。人民路周辺の**再回首鶏肉米線（再回首鸡肉米线・人民路一店）**は昼食または夕食の候補です。近隣の雲南料理店を選ぶこともできます。

### 交通と入場料

- 大理古城の公共の通り、龍龕埠頭、洱海生態回廊の公共遊歩道は無料です。
- 古城と龍龕埠頭は比較的近く、配車での移動が便利です。交差点の歩行者エリアや生態回廊では現地の管理に従ってください。
- 西岸の交通が滞っている場合は、午後の龍龕埠頭での滞在を短縮し、夕方に古城へ戻る時間を確保します。

## 11月18日｜蒼山を一日かけて歩く {#nov-18}

**ルート**：民宿 → 感通ロープウェイで登山 → 清碧渓 → 玉帯雲遊路を北上 → 七龍女池 → 中和寺 → 中和ロープウェイで下山 → 民宿。山上の滞在は約 **7時間**、徒歩は約 **11.5km**を予定し、2つのロープウェイを利用します。

感通ロープウェイから中和ロープウェイへ抜ける方向のコースです。約11.5kmは、2つのロープウェイ間のルートについて公開旅行ガイドが示す推定距離です。大理旅游網が紹介する玉帯雲遊路全線の距離は約18kmとされ、起終点や支線の数え方が異なるため、現地の実距離には差が出る場合があります。当日は景区が開放している玉帯路だけを歩き、地図アプリが自動生成する斜面の横断ルートは使わないでください。

|---|---|---|---|

表の時刻は乗り継ぎが理想的に進んだ場合の目標で、ロープウェイの運行時刻を保証するものではありません。午前の歩行区間は合計約11.5km、歩行時間は約3時間の見込みで、七龍女池には別途約10分を取っています。かなり速いペースのため、序盤の撮影は短めにし、時間を取り戻そうとして途中で走らないでください。

### 精進料理と時間のリスク

公開旅行ガイドには、中和寺の精進料理は **11:30ごろ提供開始、1人¥20、売り切れ次第終了**とありますが、景区による当日の提供保証ではありません。この予定では到着が約 **12:40**となるため、売り切れまたは提供終了の可能性が明らかにあります。精進料理を必ず食べられる前提にはしないでください。出発時にロープウェイ係員または寺院へ当日の提供状況を確認し、昼食と高カロリーの補給食を携帯してください。精進料理を最優先にする場合は、現地スタッフの助言に従って歩く速度やルートを調整します。

### ロープウェイ、チケット、開放状況の確認

今回は**感通ロープウェイで片道上り、中和ロープウェイで片道下り**を利用します。同じロープウェイの往復ではありません。公開情報だけでは、11月18日にそれぞれの片道券を購入できるか、別々のロープウェイで共通券を使えるか、景区入場料を含む総額がいくらか確認できず、チケットは未購入です。感通ロープウェイ山麓駅で購入する前に、次の点を確認してください。

- 感通ロープウェイの片道上り券と中和ロープウェイの片道下り券を別々に購入できるか、各券を指定の駅でのみ使う必要があるか。
- 清碧渓から中和寺まで玉帯路の全区間が開放されているか、臨時閉鎖や入場制限がないか。
- 中和ロープウェイの下り運行予定と、最終の乗車可能時刻。

大理旅游集散中心のウェブサイトにある時刻表は **2017年3月15日公開**です。同表では、感通ロープウェイは **09:00〜15:00が上下運行、15:00〜17:00は下りのみ**、中和ロープウェイは **09:00〜13:00が上下運行、13:00〜17:00は下りのみ**とされています。この古い表は参考情報にとどめ、当日の時刻、運休、販売状況はロープウェイ駅の掲示に従ってください。中和ロープウェイの下り券と遊歩道の開放を確認できない場合は、片道縦断を始めず、スタッフが安全と確認したルートに変更し、利用可能と確認できたロープウェイから下山してください。

### 撮影と安全

**09:20〜09:30、清碧渓**：渓流、岩壁、林間の光を撮ります。まず開放された展望場所で撮影し、その後に玉帯路へ進みます。**09:30〜12:40、玉帯路**：林、峡谷、洱海の遠景を中心に撮影し、午前中は時刻を意識して滞在を短くします。**13:10〜15:30、中和寺周辺**：寺院建築、林の重なり、洱海と大理古城の遠景を撮影します。広角で周囲を写し、望遠で尾根や街並みを引き寄せる方法もあります。**16:00〜16:30、中和ロープウェイで下山**：リフト沿線から林、洱海、大理盆地を撮れる場合がありますが、見える角度や光は天候と座る向きによります。

リフトでは安定して座り、身を乗り出したり立ち上がったりせず、カメラやスマートフォンを機材の外へ突き出さないでください。スマートフォンとカメラにはストラップを付けます。蒼山の遊歩道は標高約 **2,600m**で、山腹は湖畔より冷えることが多いため、防風・防寒着、手袋、滑りにくいハイキングシューズ、約 **1.5〜2Lの飲料水**、予備の昼食を用意してください。強風、雨、凍結、またはスタッフから通行を止められた場合は現地規制に従い、ロープウェイに間に合わせるために無理に通過しないでください。時間のチェックポイントを過ぎた場合は、スタッフに最も近い開放中の下山ルートをすぐ確認してください。

### 当日の天気の目安

中国天気網が **11月17日11:30**に発表した大理市街の予報は約 **5〜18°C**です。人民日報雲南チャンネルは、蒼山で **11月9日**に降雪があり、その後、山頂や中腹に雲霧が見られたと報じています。ただし、この報道だけでは11月18日の遊歩道に雪や凍結が残るかは分からず、路面が乾いていることも確認できません。大理市街の予報は標高約2,600mの山腹を示すものではないため、防寒着、防風ジャケット、手袋を用意してください。朝、チケット購入前に山上の実況、遊歩道とロープウェイの運行情報を再確認します。凍結、強風、または区間規制が確認された場合は、縦断を開始せず、または続行しないでください。

### 羅荃半島と昼食

**羅荃半島**：洱海東岸にあり、主な見どころは天鏡閣、羅荃塔、湖畔の遊歩道です。天鏡閣から見学を始め、羅荃塔周辺まで歩けます。一般入場券の公開参考価格は **1人¥28〜**。塔への入場は別料金の場合があります。チケットは景区の窓口または公式窓口で当日の案内を確認してください。

**向陽村での昼食**：民家苑で銅鍋牛肉を食べるか、民宿近くで地元の家庭料理や餌絲などを選べます。午後の行動範囲は海東鎮向陽村周辺にとどめると、民宿で荷物を受け取りやすくなります。

### 空港への移動

- **17:30**に民宿を出発し、大理鳳儀空港へ向かいます。ナビの目的地は「大理鳳儀空港 国内線出発」です。民宿から空港までの公開ルートは約19km、所要時間は通常約30〜50分です。
- **18:00〜18:20**の空港到着を目指します。先に搭乗手続きと荷物の預け入れを済ませ、その後、保安検査を受けます。
- 航空便は **20:35**発、**11月20日00:05**に上海浦東T2着の予定です。搭乗手続きと搭乗の締め切りは、春秋航空からの当日の案内と搭乗券で確認してください。
- 浦東空港に深夜到着後は、実際の到着時刻に応じてタクシーまたは空港の夜間交通を利用できます。
