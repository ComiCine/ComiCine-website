# 英国学部課程・5つの出願専攻の徹底解説

## Imperial、UCL、UAL：数学、メディア、映画制作専攻の比較

この5つの専攻は、英国の3つの大学に属しています。

- Imperial College London（インペリアル・カレッジ・ロンドン）：Mathematics BSc
- UCL（ユニバーシティ・カレッジ・ロンドン）：Mathematics BSc、Media BA
- UAL（ロンドン芸術大学）傘下の LCC（ロンドン・カレッジ・オブ・コミュニケーション）：Film and Television BA、Film Practice BA

公式サイトで公開されている2027年度学部入学の情報に基づいて分析します。各専攻で何を学ぶのかを説明するだけでなく、ひとつの重要な前提も考慮します。

この5つの専攻は、同じ学生の出願先です。

つまり、専攻同士のつながり、出願書類に互換性があるかどうか、そしてこの出願の組み合わせが示す学問的な方向性を、あわせて分析する必要があります。

## 1. 5つの専攻の全体比較

| 大学と専攻 | 中心となる方向 | 学位 | 修業年限 | 主な育成目標 |
| --- | --- | --- | --- | --- |
| Imperial Mathematics | 純粋数学、応用数学、数理モデリング | BSc | 3年 | 数学理論と定量的研究 |
| UCL Mathematics | 純粋数学、応用数学、数学的方法 | BSc | 3年 | 数学研究、モデリング、解析 |
| UCL Media | デジタルメディア、映像、ゲーム、インタラクティブメディア | BA | 3年 | デジタルメディアの創作と批判的研究 |
| UAL Film and Television | 映画とテレビのコンテンツ制作 | BA (Hons) | 3年 | 映像制作と業界での実践 |
| UAL Film Practice | 映画制作、ナラティブ、創作実践 | BA (Hons) | 3年 | 映画の作り手と専門制作スタッフ |

このうち：

- BSc（Bachelor of Science）：理学士。
- BA（Bachelor of Arts）：文学士／芸術学士。
- BA (Hons)：優等文学士／芸術学士。英国で一般的な学部の優等学位の形式であり、この2つの UAL 専攻が UCL の BA より一段上であることを意味するものではありません。

この5つの専攻は、おおまかに3つの方向に分けられます。

- **方向 A：数学と定量科学**：Imperial Mathematics + UCL Mathematics
- **方向 B：学際的デジタルメディア**：UCL Media
- **方向 C：専門的映像制作**：UAL Film and Television + UAL Film Practice

これは互いに近い5つの専攻ではありません。2つの数学専攻と2つの映画制作専攻の間には大きな隔たりがあり、UCL Media はその中間に位置する、比較的学際的な性格を持つ選択肢です。

## 2. Imperial College London — Mathematics BSc

- 大学：Imperial College London（インペリアル・カレッジ・ロンドン）
- 専攻：Mathematics BSc（数学理学士）
- 学習地：South Kensington、ロンドン
- 修業年限：3年
- UCASコード：G100
- 公式コース：[Imperial Mathematics BSc](https://www.imperial.ac.uk/study/courses/undergraduate/mathematics-bsc/)

### 1. この専攻では実際に何を学ぶのか？

Imperial の Mathematics は、数学理論と応用を同等に重視する一方で、学問的な要求水準が非常に高い学部プログラムです。

高校数学の延長として解法テクニックを学び続けるのではなく、学生には次のことを理解することが求められます。

- 数学の概念はなぜ成り立つのか？
- ある定理はどのような条件を満たす必要があるのか？
- 厳密な数学的証明をどのように構築するのか？
- 現実世界の問題をどのように数学で記述するのか？
- 抽象的な数学理論を計算、統計、科学にどのように応用するのか？

たとえば、高校数学では関数の極限を求めることが求められるかもしれませんが、大学数学ではさらに次のことを研究します。

極限はどのように厳密に定義されるのか？どのような条件のもとで極限は存在するのか？ある結論は証明できるのか？

そのため、Imperial の数学専攻は、抽象的思考、証明能力、そして数学的構造の理解をより重視します。

### 2. 3年間の主な学習内容

| 学年 | 科目例 | 内容の説明 |
| --- | --- | --- |
| 1年次 | Analysis 1 | 解析学。極限、数列、級数、関数を研究 |
| 1年次 | Linear Algebra and Groups | 線形代数、ベクトル空間、線形変換と群論の基礎 |
| 1年次 | Calculus and Applications | 微積分とその応用 |
| 1年次 | Probability and Statistics | 確率論、統計とデータ分析 |
| 1年次 | Introduction to Computation | Python プログラミングと数学的計算 |
| 2年次 | Analysis 2 | 高次元の解析学と位相の概念 |
| 2年次 | Linear Algebra and Numerical Analysis | 線形代数と数値計算法のさらなる研究 |
| 2年次 | Multi-variable Calculus and Differential Equations | 多変数微積分と微分方程式 |
| 3年次 | Mathematical Finance | 数理ファイナンスとオプション価格付け |
| 3年次 | Methods for Data Science | データサイエンスの数学的手法 |
| 3年次 | Markov Processes | マルコフ過程と確率モデル |
| 3年次 | Mathematical Logic / Number Theory | 数理論理学、数論などの純粋数学分野 |

これらは公式サイトに掲載されている代表的なモジュールであり、すべての学生が表中のすべての科目を履修しなければならないわけではありません。Imperial は50以上の専門モジュールを提供しており、学生は規定に従って選択します。

### 3. 学問的な特徴

**第一に、数学的証明が非常に重要です。**

学生は計算中心の思考から理論中心の思考へと、段階的に移行する必要があります。高校数学の成績が優秀であっても、大学の証明科目にすぐに適応できるとは限りません。

**第二に、選択の幅が広いことです。**

基礎科目を終えた後、学生はさまざまな方向に進むことができます。

- 純粋数学：代数、解析、数論、幾何
- 応用数学：流体力学、微分方程式、科学的モデリング
- 確率・統計：確率過程、統計的推測
- 計算数学：数値解析、データサイエンス
- 数理ファイナンス：リスク、価格付け、金融モデル

**第三に、試験と自主学習の比重が高いことです。**

公式サイトに示されている典型的な評価構成は筆記試験が中心で、研究プロジェクト、課題、プレゼンテーションも含まれます。

### 4. 2027年度の出願要件

| 項目 | 公式要件 |
| --- | --- |
| A-Level | A\*A\*A から A\*A\*AA |
| 重要科目 | Mathematics A\*、Further Mathematics A\* |
| IB最低基準 | 39点 |
| IB数学要件 | HL Mathematics 7 |
| 数学入学試験 | TMUA |
| 留学生の年間学費 | £44,850（2027年入学） |

Imperial は IB 数学について Mathematics: Analysis and Approaches（AA）をより好みますが、HL Applications and Interpretation（AI）も受け入れています。A-Level の学生については、在籍校で Further Mathematics が提供されていない場合に特別な事情を考慮する仕組みがあり、上級数学を履修していない人にはまったく機会がないと単純に理解すべきではありません。

### 5. 卒業後の進路

Imperial 数学の卒業生は、さらに次の進路を検討できます。

- 数学、統計学、応用数学の研究
- クオンツ・ファイナンスとリスクモデリング
- データサイエンス、機械学習、人工知能
- ソフトウェアアルゴリズム、数理モデリング
- アクチュアリー、コンサルティング、ビジネス分析

注意すべき点として、数学の学士号が提供するのは理論と分析の基礎であり、卒業すれば自動的に AI エンジニアやクオンツリサーチャーとしての職業スキルをすべて身につけているという意味ではありません。

**向いている学生：** 抽象数学、論理的推論、難問の解決を心から好み、高度な数学を学び続ける意欲がある学生です。単に数学の成績が良い、あるいは大学の知名度が高いという理由だけではないことが大切です。

## 3. UCL — Mathematics BSc

- 大学：University College London（ユニバーシティ・カレッジ・ロンドン）
- 専攻：Mathematics BSc（数学理学士）
- 学習地：Bloomsbury、ロンドン
- 修業年限：3年
- UCASコード：G100
- 公式コース：[UCL Mathematics BSc](https://www.ucl.ac.uk/study/prospective-students/undergraduate/courses/mathematics-bsc)

### 1. 専攻の位置づけ

UCL Mathematics も、数学という学問そのものを中心とした学部課程です。

4つの重要な基礎分野を含んでいます。

1. Algebra（代数）：数学的構造、行列、群、ベクトル空間など。
2. Analysis（解析学）：極限、連続性、微分、積分、およびより高度な解析理論。
3. Applied Mathematics（応用数学）：数学を用いて運動、物理系、現実のモデルを研究。
4. Mathematical Methods（数学的方法）：微分方程式、数値計算法、計算技法などを研究。

カリキュラムは、確かな基礎の上でより高度なモジュールを選択することを重視しており、30以上の専門選択モジュールを提供しています。

### 2. 3年間の学習構成

**1年次：数学の基礎を築く**

解析学、代数、確率・統計、力学、発展的な微積分、プログラミング、ベクトル解析を含みます。

たとえば、Programming and Vector Calculus はプログラミングと数学的ツールを組み合わせますが、学生がコンピュータサイエンスの学位を学んでいるという意味ではありません。

**2年次：段階的な専門化**

引き続き次の科目を学びます。

- Complex Analysis（複素解析）
- Further Linear Algebra（発展線形代数）
- Ordinary Differential Equations（常微分方程式）
- Fourier Methods and Partial Differential Equations（フーリエ法と偏微分方程式）

さらに、数論、群と環、幾何、計算数学などの分野からモジュールを選択します。

**3年次：専門分野を深める**

さらに次の科目を選択履修できます。

- Measure Theory（測度論）
- Functional Analysis（関数解析）
- Galois Theory（ガロア理論）
- Algebraic Topology（代数的位相幾何学）
- Geophysical Fluid Dynamics（地球物理流体力学）

これらの科目はすでにかなり深い数学理論の領域に入っており、高校数学の知識を単純に延長したものではありません。

### 3. UCL と Imperial の数学はどう違うのか？

| 比較の観点 | Imperial Mathematics | UCL Mathematics |
| --- | --- | --- |
| 学問的基礎 | 純粋数学と応用数学 | 純粋数学と応用数学 |
| 1年次の重点 | 証明、解析、代数、計算、研究 | 解析、代数、確率、応用数学、プログラミング |
| 上級学年の選択肢 | 50以上の専門モジュール | 30以上の専門モジュール |
| 学際的な余地 | I-Explore などの科目制度あり | 条件に応じて経済、統計、コンピュータ、語学など他学科のモジュールを選択可能 |
| 評価方法 | 筆記試験が中心で、課題と研究を組み合わせる | 筆記試験が中心で、課題は少量 |
| 出願時の追加試験 | TMUA | 通常の A-Level ルートで所定の条件を満たす場合は STEP 不要、代替ルートでは STEP または AEA が求められる場合あり |

どちらも厳密な数学の学位です。大学名だけで一方が研究寄り、もう一方が応用寄りだと判断することはできません。実際の方向性は、学生が後半2年間でどの科目を選ぶかに大きく左右されます。

### 4. 2027年度の出願要件

| 項目 | 公式要件 |
| --- | --- |
| A-Level標準要件 | A\*A\*A |
| 重要科目 | Mathematics と Further Mathematics のいずれも A\* |
| A-Levelの別ルート | A\*AA。うち数学と上級数学は A\*、A で、STEP 2 または Mathematics AEA Distinction と組み合わせる |
| IB標準要件 | 40点、HL 3科目合計20点、HL数学7 |
| IBの別ルート | 39点、HL条件を満たし、STEP 2 または AEA Distinction と組み合わせる |
| IB数学の種類 | HL Mathematics: Analysis and Approaches のみ受け入れ |
| 留学生の年間学費 | £44,400（2027/28） |

ここに挙げたのは一般的な出願基準であり、contextual offer などの特別な制度については詳しく触れていません。

### 5. 卒業後の進路

UCL 数学の卒業生も、次のような進路を選ぶことができます。

数学研究、金融、アクチュアリー、統計、データサイエンス、テクノロジー企業、コンサルティング、教育など。

**向いている学生：** しっかりした数学の基礎を持ち、厳密な数学理論を学びたいと考えると同時に、金融、データサイエンス、コンピュータ、その他の数学応用分野へ進む可能性も残しておきたい学生です。

## 4. UCL — Media BA

- 大学：University College London（ユニバーシティ・カレッジ・ロンドン）
- 専攻：Media BA（メディア学文学士）
- 学習地：UCL East、Stratford、ロンドン
- 修業年限：3年
- UCASコード：P300
- 公式コース：[UCL Media BA](https://www.ucl.ac.uk/study/prospective-students/undergraduate/courses/media-ba)

### 1. これはどのようなメディア専攻なのか？

5つの専攻の中で、これは最も個別に説明する価値がある専攻です。誤解されやすいからです。

UCL Media BA は、伝統的なジャーナリズム・コミュニケーション専攻でもなければ、撮影、編集、監督だけを教える映画学校のカリキュラムでもありません。

重視しているのは次の点です。

> 現代のデジタルメディアが社会にどのような影響を与えるのかを理解し、映像、ゲーム、インタラクティブ技術、新興メディアを通じて創造的な実践を行うこと。

カリキュラムは3つの層を組み合わせています。

- Media Theory（メディア理論）：メディアが文化、社会、アイデンティティ、情報の伝播、人々の行動にどのような影響を与えるかを研究します。
- Creative Media Practice（クリエイティブメディア実践）：短編映像、デジタルコンテンツ、ゲーム、インタラクティブ作品を制作します。
- Emerging Media Technologies（新興メディア技術）：VR、AR、人工知能、デジタルな世界構築などの技術を探求します。

そのため、この専攻には芸術性に加えて、社会科学と技術の側面もあります。

たとえば：

ある学生が、人工知能が映画制作をどう変えるのかを研究したいと考えているとします。

この専攻では、AI ツールを使って映像を制作する方法を学ぶだけでなく、AI 生成コンテンツに関わる作者性、創作の帰属、文化的影響、そして観客がそうした作品をどう理解するのかも研究することになるかもしれません。

これが UCL Media と伝統的な映画制作専攻との重要な違いです。

### 2. 中核となる科目内容

| 科目の英語名 | 日本語での説明 | 具体的に研究する内容 |
| --- | --- | --- |
| Introduction to Creative Media Practice | クリエイティブメディア実践入門 | 創作の構想、実践の方法と制作の基礎 |
| Digital Cultures and Society | デジタル文化と社会 | ソーシャルメディア、インターネットと社会文化 |
| Short Fiction Films | 短編劇映画 | 劇映画の映像創作 |
| Creative Media Lab | クリエイティブメディア・ラボ | 創作の実験と実践プロジェクト |
| Worldbuilding for Games, Interactive and Cinematic Experiences | ゲーム、インタラクティブ、映画の世界構築 | 仮想環境、物語世界、インタラクティブ体験 |
| Designing for VR/AR | 仮想現実・拡張現実のデザイン | 没入型メディア体験 |
| Machine Learning and Creative AI | 機械学習とクリエイティブAI | クリエイティブメディアにおける人工知能の応用 |

| Filmic Fictions | 映画の物語 | 映像によるフィクションの構築 |

このうち一部は後の学年の選択科目であり、すべてが必修というわけではありません。

### 3. 3年間の学習の流れ

**1年次：メディア領域に幅広く触れる**

基礎的な映画制作、デジタル文化、メディア理論、ゲーム、インタラクティブデザインを学びます。

この段階では、監督、編集、撮影のいずれかの役割に早くから限定するのではなく、幅広いメディアリテラシーを身につけることが期待されています。

**2年次：自分が関心を持つ方向を選ぶ**

学生はさまざまな方向に進むことができます。

- 映画：ドキュメンタリー、劇映画、映像ナラティブ
- ゲーム：ゲーム開発、インタラクティブ体験
- 技術系メディア：VR/AR、クリエイティブ AI
- 研究：デジタル文化、メディア理論、クリエイティブ経済

さらに、業界に関連する実践やインターンシップのモジュールを履修する機会もありますが、枠と手配によって異なります。

**3年次：独立した研究と創作プロジェクトを完成させる**

学生は研究と創作制作を組み合わせ、大規模なプロジェクトや卒業論文を通じて自らの能力を示す必要があります。

評価には論文やレポートだけでなく、映像作品、ブログ、ポッドキャスト、口頭発表、ポートフォリオが含まれる可能性もあります。

### 4. 2027年度の出願要件

| 項目 | 要件 |
| --- | --- |
| A-Level | AAB |
| 好ましい科目 | 芸術、人文学系科目または Computer Science |
| IB | 36点、HL 3科目合計17点、かつ HL 各科目5以上 |
| ポートフォリオ | 提出が必要 |
| 留学生の年間学費 | £44,400 |
| 授業の場所 | Bloomsbury のメインキャンパスではなく UCL East |

ここには見落とされやすい重要なポイントがあります。

UCL Media BA の出願にはポートフォリオが必要であり、A-Level や IB の成績と志望理由書（Personal Statement）を提出するだけでは足りません。

公式要件では、ポートフォリオは単一の PDF として提出します。

- 作品は最大6点
- PDF は12ページ以内、50 MB 以内
- 映像、アニメーション、写真、脚本、ゲームのプロトタイプ、3D作品などを含めることができる
- 作品のコンセプト、制作過程、個人の貢献を説明する必要がある
- 動画などのメディアは PDF 内のリンクで提示できる

公式サイトでは作品の説明と対応する画像資料も求められており、制作する際は UCL が発行する具体的な提出ガイドラインに厳密に従う必要があります。

### 5. 卒業後の進路

純粋な映画制作の職種と比べて、この専攻のキャリアの範囲はより広くなっています。

- デジタルコンテンツの制作と企画
- インタラクティブメディアと没入型体験のデザイン
- ゲームとデジタルナラティブ
- クリエイティブテクノロジーとニューメディアのプロジェクト
- デジタル文化研究
- 映像の創作と制作
- 文化機関、芸術機関、メディア産業

**向いている学生：** 映画、デジタル文化、ゲーム、人工知能、インタラクティブ技術に分野横断的な関心を持ち、理論研究に取り組む意欲があると同時に、実際に創作作品を制作したいと考える学生です。

特に注意すべき点として、カリキュラムには機械学習やゲーム開発が含まれていますが、コンピュータサイエンスや AI エンジニアリングの専攻と同じではなく、技術訓練の深さと育成目標が異なります。

## 5. UAL — BA (Hons) Film and Television

## 8. 重点分析：同じ人がこの5つの専攻に出願することは何を意味するのか？

これは、この出願の組み合わせ全体における最も重要な問題です。

### 1. この専攻の組み合わせには明らかな学問的な隔たりがある

カリキュラムの内容から見ると、5つの専攻の関係はおおよそ次のとおりです。

- 2つの数学専攻の知識体系は非常に近い。
- 2つの UAL 専攻の知識体系は非常に近い。
- UCL Media と2つの UAL 専攻には、映像実践において明らかな重なりがある。
- 数学と映像の間には、同じように直接的なカリキュラムの重なりはない。

したがって、この出願は数学とクリエイティブメディアという2つの軸が同時に存在しているものと理解できます。

ただし、5つの選択肢だけでは、学生が実際にどちらの方向をより好んでいるのかを断定することはできず、その出願動機を推測することもできません。

### 2. この5つの専攻で、筋の通った個人の学問的ストーリーを形成できるか？

可能です。ただし、志望理由書だけで5つの専攻を無理につなげるのではなく、実際の経験による裏付けが必要です。

考えられる学問的関心のひとつは次のようなものです。

Mathematics + Computational Creativity + Digital Media + Film

たとえば：

- 学生が幾何、確率、計算数学に深い関心を持っている。
- 同時に、プログラミング、アルゴリズム、映像技術を用いて創作プロジェクトを完成させたことがある。
- 数理モデルとコンピュータグラフィックス、視覚表現の関係を研究したことがある。
- さらに実際に映画を制作し、脚本、絵コンテ、撮影、編集の経験を積んでいる。

このような背景があれば、数学とメディアは計算創造性、デジタル映像、視覚技術を通じて結びつけることができます。

具体例を挙げます。

ある学生が、プログラムで生成した視覚効果を用いた短編映像を制作したことがあるとします。

その場合、学生はこのプロジェクトをさまざまな学問的観点から研究することができます。

| 観点 | 研究できる問い |
| --- | --- |
| 数学 | 幾何変換、数理モデル、アルゴリズムの原理 |
| UCL Media | デジタルビジュアルが物語と観客体験にどのような影響を与えるか |
| Film and Television | 視覚効果をどのように映像制作のワークフローに組み込むか |
| Film Practice | 映像言語、編集、音響を用いて創作テーマをどのように表現するか |

これは、実際の学際的な基盤を持つ出願ストーリーになるでしょう。

ただし強調しておく必要があります。上記はあくまで考えられる事例であり、この学生の実際の経験についての判断ではありません。

### 3. 最大の問題：UCAS Personal Statement は1通しかない

これがこの出願の主なリスクです。

英国の学部課程では、UCAS を通じて一般に最大5つの専攻を選択でき、この5つの専攻でちょうど5つの選択枠をすべて使い切ることになります。

申請者には UCAS Personal Statement が1通しかなく、それをこれらすべての専攻に共通して使う必要があります。

さらに：

- Imperial は代わりとなる志望理由書を別途提出することを受け付けていません。
- UCL も、大学側から求められない限り、修正版や追加の志望理由書を一般に受け付けていません。
- UCL では2つの異なる専攻に同時に出願できますが、それぞれが UCAS の出願枠を1つずつ使います。

2027年度入学では、3つの質問からなる構成が採用されています。

| UCASの質問 | 執筆の目的 |
| --- | --- |
| Why do you want to study this course or subject? | なぜその専攻を学びたいのか |
| How have your qualifications and studies helped you to prepare? | これまでの学業がどのように準備に役立ったか |
| What else have you done outside education, and why is it useful? | 課外での経験と専攻への準備 |

全文で合計4,000文字（スペースを含む）以内、各質問は350文字以上です。

#### なぜこれが難しさを生むのか？

申請者が数学を中心とした志望理由書を書いたとします。

> 私が最も関心を持っているのは数学的証明、抽象代数、数論であり、数学の論理構造をさらに探求したいと考えています。

これは数学専攻には明らかに関連していますが、UAL Film Practice にとっては、学生がなぜ映画制作の訓練を受けたいのかを十分に説明できない可能性があります。

逆に、志望理由書が主に次のような内容だった場合：

> 私は映画監督になりたいと考えており、カメラの言語と映像ナラティブを通じて感情を表現することが好きです。

映画方向への関心を示すには有利ですが、Imperial Mathematics への出願に必要な数学への学問的動機を示すには不十分です。

しかも、この矛盾は、志望理由書に「私は数学も映画も好きです」という一文を数行加えるだけで解消できるものではありません。

特に注意すべき点として、大学は通常、合否を決定する際に申請者の他大学への出願先をすべて見ることはありませんが、同じ志望理由書は目にします。したがって問題は、5つの出願先の並びが自動的に不合理と判断されることではなく、各専攻から見た出願の論証が十分に的を絞ったものになっているかどうかにあります。

## 9. この出願が本当に妥当かどうかをどう判断するか？

以下に、いくつかの異なる実際の状況を示します。

### ケース A：学生の数学が非常に強く、実際の映像作品もある

学生が優れた数学の学業背景を持ち、同時にすでに短編映画、ドキュメンタリー、インタラクティブメディア作品を完成させている場合、この組み合わせには妥当性があります。

ただし、申請者は依然として2種類の異なる能力の証拠を準備する必要があります。

**数学の方向：**

- 数学理論と証明の能力
- 授業の要求を超えた数学の探求
- 数学の読書、研究、コンテストの経験
- TMUA などの入学試験の準備

**メディアと映画の方向：**

- 映画またはニューメディアの作品
- 創作過程、研究、振り返り
- 作品における具体的な個人の貢献
- 映像ナラティブやメディア技術に関する探求

このような学生にとっての中心的な課題は必ずしも能力ではなく、限られた出願書類の中で2つの関心をいかに十分に証明するかにあります。

### ケース B：学生の数学の成績は非常に良いが、本当の関心は映画にある

この場合、次の点を考える必要があります。

なぜそれでも Imperial と UCL の数学を選ぶのか？

もし数学を選ぶ理由が単に成績が良いから、あるいは他の専攻の「保険」としてであるなら、両大学の数学カリキュラムはいずれも非常に理論的であり、成績が要件に達しているからといって必ずしも学生に合っているわけではないことを理解する必要があります。

いったん大学に入学すると、解析学、代数、微分方程式、数学的証明が学習の主要部分を占めることになります。

これは、長期的に映画創作に取り組む日々の学習体験とはまったく異なります。

### ケース C：学生は数学を学びたいが、映像は単なる趣味である

この場合、3つのメディア・映像の選択肢が適切かどうかも、改めて見直す価値があります。

なぜなら、UAL Film Practice と Film and Television はかなり専門化された職業実践のカリキュラムだからです。学生は大量の制作作業をこなし、チームプロジェクトに積極的に参加する必要があります。

関連する創作に長期的に携わるつもりがないのであれば、それらを純粋数学専攻の滑り止めとして位置づけるのは、理想的な戦略ではないかもしれません。

### ケース D：学生が数学とクリエイティブテクノロジーの両方に真剣に取り組んでいる

その場合、UCL Media は確かに学際的な特徴を持つ方向になり得ます。

ただし、次の点を理解しておく必要があります。

UCL Media は、数学、コンピュータサイエンス、AI、映画という4つの専攻を統合したものではありません。

メディア理論とクリエイティブメディア実践を中心としています。クリエイティブ AI や VR/AR などの科目を履修することはできますが、中核となる育成方向はやはり高度な数学ではありません。

学生が将来、コンピュータグラフィックスの研究、視覚アルゴリズム、機械学習エンジニアリングに取り組みたいと明確に考えているのであれば、やはりコンピュータサイエンスおよび関連する数学・工学のカリキュラムと比較する必要があります。

## 12. この出願に対する総合評価

この5つの専攻の組み合わせには、特に注目すべき点が3つあります。

### 第一：数学と映画は明らかに異なる2つの学部育成ルートである

数学の学部課程は、主に抽象理論、厳密な証明、数理モデルを研究します。

映画の学部課程は、創造的な表現、映画制作の技術、物語の構成力、チームでの協働を重点的に育成します。

これらの能力はデジタルクリエイティブの領域で互いに支え合うことはできますが、同じ種類の学問的訓練ではありません。

したがって、最終的にどの専攻を選ぶかは、本質的には今後3年間をどちらの訓練に主に注ぐかを決めることを意味します。

### 第二：UCL Media は学際的な特色を持つ選択肢だが、両方を完全に置き換えることはできない

UCL Media は、デジタル文化、技術、インタラクティブデザイン、映像創作を結びつけることができます。

技術に関心を持つ作り手にとっては、比較的魅力的かもしれません。

しかし、学生の目標が高度な数学研究であれば数学の BSc の代わりにはならず、本格的な専門映画技術の訓練を受けることが目標であれば、UAL のカリキュラムの詳細と慎重に比較する必要もあります。

### 第三：本当に解決すべきは出願ナラティブの一貫性である

この5つの専攻がすでに確定しているのであれば、出願書類を準備する際には、まず明確な経験対応表を作成することをおすすめします。

| 実際の経験の種類 | 裏付けとなる専攻 |
| --- | --- |
| 数学の定理、証明、数理モデルを深く研究した | Imperial Mathematics、UCL Mathematics |
| プログラミングやアルゴリズムを用いて視覚的な創作を行った | UCL Media、さらに数学の応用的関心を裏付ける可能性あり |
| 完結した物語を持つ短編映画を制作した | UCL Media、UALの2つの映画専攻 |
| 映像チームの制作に参加し、具体的な役割を担った | UALの2つの映画専攻 |
| デジタルメディア、インタラクティブ技術とその社会的影響を研究した | UCL Media |
| 数学の問題と計算映像技術を組み合わせた独立プロジェクト | 数学とメディアの両方向の裏付けとなる可能性があるが、各コースの重点に沿って説明する必要がある |

この表の意義は、実際に取り組んできたことから出発して専攻への関心を証明することにあります。先に学際的に聞こえるストーリーを作り、それに合わせて経験を探すのではありません。

## 最終結論

専攻同士の関係だけから見ると：

- **Imperial Mathematics と UCL Mathematics**：一貫した数学の出願ルート。
- **UCL Media、UAL Film and Television、UAL Film Practice**：デジタルメディアから専門的な映画制作へと至るクリエイティブ方向のルート。
- **最も明らかな出願上の課題**：5つの専攻に同時に出願できないことではなく、学問的な隔たりが大きく、ひとつの UCAS 志望理由書でまったく異なる学問的期待に同時に応える必要があることです。

学生が数学と映像の両分野でしっかりした実際の経験を持っているのであれば、これは一定の妥当性を持つ分野横断的な出願になり得ます。一方、主に異なる大学の知名度と入学条件を組み合わせることが目的であれば、専攻との適合性と入学後の学習体験を慎重に評価する必要があります。

この学生について、さらに確認することを最もおすすめしたいのは次の3点です。A-Level/IB の具体的な科目と予想成績、映画やメディアのポートフォリオがすでにあるかどうか、そしてこの学生が数学研究、デジタルクリエイティブ、映画制作のどれに取り組みたいと考えているかです。この3点は、大学ランキングを単独で比較するよりも、この5つの選択がこの学生に適しているかどうかを判断する手がかりになります。
