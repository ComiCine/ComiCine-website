# セキュリティへの謝辞

## はじめに

脆弱性を責任ある方法で報告し、ComiCine のセキュリティ向上にご協力くださる独立したセキュリティ研究者とセキュリティコミュニティの皆様に感謝します。安全性の向上に向けた慎重なご協力を大切にしています。

## 謝辞の方針

- 責任ある方法で開示され、検証された脆弱性について謝辞を掲載する場合があります。
- 公開するかどうかは ComiCine の裁量によります。
- 研究者の同意なく、氏名その他の個人を特定できる情報を公開しません。匿名での謝辞を希望できます。
- 謝辞は金銭的な報酬を意味しません。
- 機密情報を露出させる可能性のある脆弱性の詳細は公開しない場合があります。

## 謝辞一覧

今後、掲載する場合は、研究者の氏名または希望する別名、貢献の概要、謝辞の日付、ならびに本人の同意がある場合に限り任意の個人ウェブサイトまたはプロフィールへのリンクを含めることがあります。

現在、公開されたセキュリティ謝辞はありません。

## 報告について

報告方法と研究ガイドラインについては、[セキュリティ脆弱性の開示ポリシー](/security/policy/ja-jp)をご確認ください。

セキュリティ連絡先：[security@comicine.com](mailto:security@comicine.com)
