# 英国本科五个申请专业深度解析

## Imperial、UCL、UAL：数学、媒体与电影制作专业对比

这五个专业来自英国三所大学：

- Imperial College London（帝国理工学院）：Mathematics BSc
- UCL（伦敦大学学院）：Mathematics BSc、Media BA
- UAL（伦敦艺术大学）旗下 LCC（伦敦传媒学院）：Film and Television BA、Film Practice BA

我按照官网公布的 2027 年本科入学信息进行分析，重点不仅是解释每个专业学什么，还会考虑一个重要前提：

这五个专业是同一个学生的申请选择。

这意味着需要同时分析专业之间的联系、申请材料是否兼容，以及这套选校组合反映出的学术方向。

## 一、五个专业的整体对比

| 学校与专业 | 核心方向 | 学位 | 学制 | 主要培养目标 |
| --- | --- | --- | --- | --- |
| Imperial Mathematics | 纯数学、应用数学、数学建模 | BSc | 3年 | 数学理论与定量研究 |
| UCL Mathematics | 纯数学、应用数学、数学方法 | BSc | 3年 | 数学研究、建模、分析 |
| UCL Media | 数字媒体、影像、游戏、交互媒体 | BA | 3年 | 数字媒体创作与批判性研究 |
| UAL Film and Television | 电影与电视内容制作 | BA (Hons) | 3年 | 影视制作与行业实践 |
| UAL Film Practice | 电影制作、叙事与创作实践 | BA (Hons) | 3年 | 电影创作者与专业制作人员 |

其中：

- BSc（Bachelor of Science）：理学学士。
- BA（Bachelor of Arts）：文学/艺术学士。
- BA (Hons)：荣誉文学/艺术学士，是英国常见的本科荣誉学位形式，不代表这两个 UAL 专业比 UCL 的 BA 高一级。

可以将这五个专业初步划分为三个方向：

- **方向 A：数学与定量科学**：Imperial Mathematics + UCL Mathematics
- **方向 B：跨学科数字媒体**：UCL Media
- **方向 C：专业影视制作**：UAL Film and Television + UAL Film Practice

这不是五个完全相近的专业。两项数学与两项电影制作之间跨度很大，而 UCL Media 是中间较有跨学科特征的选择。

## 二、Imperial College London — Mathematics BSc

- 学校：Imperial College London（帝国理工学院）
- 专业：Mathematics BSc（数学理学学士）
- 学习地点：South Kensington，伦敦
- 学制：3年
- UCAS代码：G100
- 官方课程：[Imperial Mathematics BSc](https://www.imperial.ac.uk/study/courses/undergraduate/mathematics-bsc/)

### 1. 这个专业到底学什么？

Imperial 的 Mathematics 是一个数学理论与应用并重、但学术要求很高的本科项目。

它不是以高中数学的方式继续学习解题技巧，而是要求学生理解：

- 数学概念为什么成立？
- 一个定理需要满足哪些条件？
- 如何构建严谨的数学证明？
- 如何用数学描述现实世界的问题？
- 如何将抽象数学理论应用于计算、统计和科学？

例如，高中数学可能要求学生求解一个函数的极限，而大学数学会进一步研究：

极限到底如何被严格定义？在什么条件下极限存在？一个结论是否能够被证明？

因此，Imperial 数学专业更重视抽象思维、证明能力和数学结构的理解。

### 2. 三年主要学习内容

| 年级 | 课程举例 | 内容解释 |
| --- | --- | --- |
| 第一年 | Analysis 1 | 数学分析，研究极限、数列、级数及函数 |
| 第一年 | Linear Algebra and Groups | 线性代数、向量空间、线性变换与群论基础 |
| 第一年 | Calculus and Applications | 微积分及应用 |
| 第一年 | Probability and Statistics | 概率论、统计与数据分析 |
| 第一年 | Introduction to Computation | Python 编程及数学计算 |
| 第二年 | Analysis 2 | 高维数学分析与拓扑概念 |
| 第二年 | Linear Algebra and Numerical Analysis | 进一步研究线性代数与数值方法 |
| 第二年 | Multi-variable Calculus and Differential Equations | 多元微积分与微分方程 |
| 第三年 | Mathematical Finance | 数理金融与期权定价 |
| 第三年 | Methods for Data Science | 数据科学的数学方法 |
| 第三年 | Markov Processes | 马尔可夫过程与随机模型 |
| 第三年 | Mathematical Logic / Number Theory | 数理逻辑、数论等纯数学方向 |

这些是官网列出的代表性模块，不是每个学生都必须学习表中所有课程。Imperial 提供超过 50 个专业化模块供学生按规定选择。

### 3. 学术特点

**第一，数学证明非常重要。**

学生需要逐步从计算型思维转向理论型思维。即使高中数学成绩优秀，也不一定意味着会立即适应大学的证明课程。

**第二，选择范围广。**

在基础课程之后，学生可以向不同方向发展：

- 纯数学：代数、分析、数论、几何
- 应用数学：流体力学、微分方程、科学建模
- 概率统计：随机过程、统计推断
- 计算数学：数值分析、数据科学
- 数理金融：风险、定价与金融模型

**第三，考试和独立学习占比高。**

官网给出的典型考核结构以笔试为主，同时有研究项目、作业和展示。

### 4. 2027 年申请要求

| 项目 | 官方要求 |
| --- | --- |
| A-Level | A\*A\*A 至 A\*A\*AA |
| 关键科目 | Mathematics A\*、Further Mathematics A\* |
| IB最低标准 | 39分 |
| IB数学要求 | HL Mathematics 7 |
| 数学入学考试 | TMUA |
| 海外学生年学费 | £44,850（2027入学） |

Imperial 对 IB 数学更偏好 Mathematics: Analysis and Approaches（AA），但也接受 HL Applications and Interpretation（AI）。对于 A-Level 学生，如果学校不提供 Further Mathematics，学校有特殊情况的考虑机制，不能简单理解为所有未修进阶数学者都绝无机会。

### 5. 毕业后的发展方向

Imperial 数学毕业生可以进一步考虑：

- 数学、统计学、应用数学研究
- 量化金融与风险建模
- 数据科学、机器学习和人工智能
- 软件算法、数学建模
- 精算、咨询、商业分析

需要注意，数学本科学位提供的是理论和分析基础，不代表毕业后自动具备 AI 工程师或量化研究员的全部职业技能。

**适合的学生：** 真正喜欢抽象数学、逻辑推理、解决难题，有持续学习高等数学的意愿，而不只是因为数学成绩好或学校知名度高。

## 三、UCL — Mathematics BSc

- 学校：University College London（伦敦大学学院）
- 专业：Mathematics BSc（数学理学学士）
- 学习地点：Bloomsbury，伦敦
- 学制：3年
- UCAS代码：G100
- 官方课程：[UCL Mathematics BSc](https://www.ucl.ac.uk/study/prospective-students/undergraduate/courses/mathematics-bsc)

### 1. 专业定位

UCL Mathematics 同样属于以数学学科本身为中心的本科课程。

它包含四个重要基础领域：

1. Algebra（代数）：数学结构、矩阵、群、向量空间等。
2. Analysis（数学分析）：极限、连续性、微分、积分以及更高阶的分析理论。
3. Applied Mathematics（应用数学）：用数学研究运动、物理系统及现实模型。
4. Mathematical Methods（数学方法）：研究微分方程、数值方法、计算技巧等。

课程强调在坚实基础上选择更高阶模块，并提供超过 30 个专业选修模块。

### 2. 三年的学习安排

**第一年：建立数学基础**

包括数学分析、代数、概率统计、动力学、进阶微积分、编程和向量微积分。

例如，Programming and Vector Calculus 将编程与数学工具结合，但这并不意味着学生在读一个计算机科学学位。

**第二年：逐步专业化**

继续学习：

- Complex Analysis（复分析）
- Further Linear Algebra（高等线性代数）
- Ordinary Differential Equations（常微分方程）
- Fourier Methods and Partial Differential Equations（傅里叶方法与偏微分方程）

并从数论、群与环、几何、计算数学等方向选择模块。

**第三年：深入专门领域**

可以进一步选修：

- Measure Theory（测度论）
- Functional Analysis（泛函分析）
- Galois Theory（伽罗瓦理论）
- Algebraic Topology（代数拓扑）
- Geophysical Fluid Dynamics（地球物理流体力学）

这些科目已经进入较深入的数学理论领域，而不是高中数学知识的简单延伸。

### 3. UCL 和 Imperial 数学有什么区别？

| 比较维度 | Imperial Mathematics | UCL Mathematics |
| --- | --- | --- |
| 学科基础 | 纯数学与应用数学 | 纯数学与应用数学 |
| 第一年的重点 | 证明、分析、代数、计算、研究 | 分析、代数、概率、应用数学、编程 |
| 高年级选择 | 超过50个专业化模块 | 超过30个专业化模块 |
| 跨学科空间 | 有 I-Explore 等课程机制 | 可按条件选择经济、统计、计算机、语言等外系模块 |
| 评估方式 | 笔试为主，结合课程作业与研究 | 笔试为主，少量课程作业 |
| 申请中的额外考试 | TMUA | 常规 A-Level 路线达到指定条件时不要求 STEP，替代路线可能要求 STEP 或 AEA |

两者都是严谨的数学学位。不能仅凭学校名称就认为一个偏研究、另一个偏应用；实际方向很大程度取决于学生后两年的选课。

### 4. 2027 年申请要求

| 项目 | 官方要求 |
| --- | --- |
| A-Level标准要求 | A\*A\*A |
| 关键科目 | Mathematics 和 Further Mathematics 均需 A\* |
| A-Level另一条路线 | A\*AA，其中数学与进阶数学为 A\*、A，并结合 STEP 2 或 Mathematics AEA Distinction |
| IB标准要求 | 40分，3门HL合计20分，HL数学7 |
| IB另一条路线 | 39分，符合HL条件，并结合 STEP 2 或 AEA Distinction |
| IB数学类别 | 仅接受 HL Mathematics: Analysis and Approaches |
| 海外学生年学费 | £44,400（2027/28） |

此处列出的是普通申请标准，未展开 contextual offer 等特殊政策。

### 5. 毕业方向

UCL 数学毕业生同样可以选择：

数学研究、金融、精算、统计、数据科学、科技企业、咨询、教育等。

**适合的学生：** 具备较强的数学基础，希望学习严谨数学理论，同时希望保留向金融、数据科学、计算机或其他数学应用方向发展的可能性。

## 四、UCL — Media BA

- 学校：University College London（伦敦大学学院）
- 专业：Media BA（媒体学文学学士）
- 学习地点：UCL East，Stratford，伦敦
- 学制：3年
- UCAS代码：P300
- 官方课程：[UCL Media BA](https://www.ucl.ac.uk/study/prospective-students/undergraduate/courses/media-ba)

### 1. 这是一个怎样的媒体专业？

这是五个专业里最值得单独解释的一个，因为它很容易被误解。

UCL Media BA 既不是传统的新闻传播专业，也不是单纯教授摄影、剪辑和导演的电影学院课程。

它强调的是：

> 理解现代数字媒体如何影响社会，并通过影视、游戏、互动技术和新兴媒介进行创造性的实践。

课程结合三个层面：

- Media Theory（媒体理论）：研究媒体如何影响文化、社会、身份、信息传播及人们的行为。
- Creative Media Practice（创意媒体实践）：制作短片、数字内容、游戏、互动作品。
- Emerging Media Technologies（新兴媒体技术）：探索 VR、AR、人工智能、数字世界构建等技术。

这就使得它既有艺术性，又有社会科学与技术方面的内容。

例如：

假设一个学生想研究人工智能如何改变电影制作。

在这个专业中，学生可能不仅需要学习如何使用 AI 工具制作一段影像，还要研究 AI 生成内容涉及的作者身份、创意归属、文化影响，以及观众如何理解这些作品。

这就是 UCL Media 和传统电影制作专业的重要区别。

### 2. 核心课程内容

| 课程英文名 | 中文解释 | 具体研究什么 |
| --- | --- | --- |
| Introduction to Creative Media Practice | 创意媒体实践导论 | 创意构思、实践方法与制作基础 |
| Digital Cultures and Society | 数字文化与社会 | 社交媒体、互联网与社会文化 |
| Short Fiction Films | 剧情短片 | 剧情影像创作 |
| Creative Media Lab | 创意媒体实验室 | 创意实验和实践项目 |
| Worldbuilding for Games, Interactive and Cinematic Experiences | 游戏、互动与电影世界构建 | 虚拟环境、叙事世界和交互体验 |
| Designing for VR/AR | 虚拟与增强现实设计 | 沉浸式媒体体验 |
| Machine Learning and Creative AI | 机器学习与创意AI | 人工智能在创意媒体中的应用 |
| Game Development Fundamentals | 游戏开发基础 | 游戏设计与制作方法 |
| Filmic Fictions | 电影叙事 | 通过影像构建虚构故事 |

其中部分为后续选修课，并非全部必修。

### 3. 三年的学习路径

**第一年：广泛接触媒体领域**

学习基础电影制作、数字文化、媒体理论、游戏和互动设计。

这一阶段希望学生建立广泛的媒体素养，而不是过早局限在导演、剪辑或摄影中的某一个角色。

**第二年：选择自己感兴趣的方向**

学生可以向不同方向发展：

- 电影：纪录片、剧情片、影像叙事
- 游戏：游戏开发、互动体验
- 技术媒体：VR/AR、创意 AI
- 研究：数字文化、媒体理论、创意经济

此外有机会修读与行业相关的实践或工作实习模块，具体取决于名额及安排。

**第三年：完成独立研究及创意项目**

学生需要将研究与创意制作结合起来，并通过大型项目或毕业论文展示自己的能力。

其考核不仅可能包括论文和报告，还可能有影像作品、博客、播客、口头展示及作品集。

### 4. 2027 年申请要求

| 项目 | 要求 |
| --- | --- |
| A-Level | AAB |
| 偏好科目 | 艺术、人文学科或 Computer Science |
| IB | 36分，3门HL合计17分，且单科HL不低于5 |
| 作品集 | 需要提交 |
| 海外学生年学费 | £44,400 |
| 授课地点 | UCL East，而非 Bloomsbury 主校区 |

这里有一个容易忽略的重点：

UCL Media BA 需要申请作品集，而不是只提交 A-Level、IB 成绩和个人陈述。

官方要求作品集以单一 PDF 形式提交：

- 最多 6 件作品
- PDF 不超过 12 页、50 MB
- 可包括影像、动画、摄影、剧本、游戏原型、3D创作等
- 需要说明作品的概念、制作过程和个人贡献
- 视频等媒体可以用 PDF 中的链接呈现

官网还要求作品说明与相应图像材料，制作时应严格对照 UCL 发出的具体提交指引。

### 5. 毕业后的发展方向

比起纯粹的电影制作岗位，这个专业的职业覆盖面更广：

- 数字内容创作与策划
- 互动媒体与沉浸式体验设计
- 游戏及数字叙事
- 创意技术与新媒体项目
- 数字文化研究
- 影视创作及制作
- 文化机构、艺术机构与媒体产业

**适合的学生：** 对电影、数字文化、游戏、人工智能和互动技术有跨领域兴趣，既愿意进行理论研究，也希望实际制作创意作品。

特别需要提醒的是，课程虽然涉及机器学习和游戏开发，但不等同于计算机科学或 AI 工程专业，技术训练的深度和培养目标不同。

## 五、UAL — BA (Hons) Film and Television

- 学校：University of the Arts London（伦敦艺术大学）
- 学院：London College of Communication（LCC）
- 专业：Film and Television BA (Hons)
- 中文：电影与电视制作（荣誉学士）
- 学制：3年
- UCAS代码：W601
- 官方课程：[UAL Film and Television](https://www.arts.ac.uk/subjects/animation-interactive-film-and-sound/undergraduate/ba-hons-film-and-television-lcc)

### 1. 专业的核心定位

这是一个非常明确的影视制作专业，教学与影视行业的实际工作流程联系紧密。

它希望培养能够参与电影、电视剧、纪录片、电视节目及其他视听内容制作的人才。

学习内容不只有艺术创作，还包括：

- Pre-production：前期策划与筹备
- Production：正式拍摄与制作
- Post-production：剪辑与后期制作
- Screenwriting：影视编剧
- Studio Production：演播室制作
- Documentary：纪录片
- Content Development：节目与内容开发
- Distribution：发行与传播

与 UCL Media 相比，这个专业更加专注影视内容如何被真正生产出来。

### 2. 三年的课程安排

**第一年：学习影视制作基础**

主要涉及影像语言、叙事结构、声音、纪实内容和团队协作。

包括：

- Introduction to Film and Television
- Screen Cultures: Narrative
- Sound, Image, Story
- Screen Cultures: Factual Stories
- Factual

特别值得关注的是 Factual（纪实内容制作），它包括纪录片、真实事件影像以及其他纪实电视内容的制作训练。

**第二年：学习专业化影视制作**

关键课程包括：

| 课程 | 学习重点 |
| --- | --- |
| TV Studio Production | 多机位拍摄、演播室制作、直播与录播 |
| The Script | 编剧、故事结构与剧本开发 |
| Drama | 剧情作品拍摄、演员合作、制作流程 |
| Story Development | 故事策划、项目提案、创意推介 |
| Screen Performances and Genres | 影视类型、角色表演与叙事技巧 |

这里的 TV Studio Production 特别能体现这一专业的特色。

学生会学习多机位环境下的制作方式，而这与单机位剧情短片的创作流程有明显不同。

**第三年：大型作品与职业发展**

主要包括：

- Dissertation（40学分）：毕业研究
- Major Project: Portfolio（60学分）：大型创意作品集项目
- Professional Perspectives（20学分）：影视行业与职业发展

学生需要展示完整的制作能力，并理解行业中如何进行内容委托、生产、营销和发行。

### 3. 2027 年申请要求

| 项目 | 要求 |
| --- | --- |
| UCAS Tariff | 104 points |
| A-Level | 接受符合要求的 Level 3 资格组合，偏好相关人文、艺术及社会科学科目 |
| IB参考最低要求 | 24分 |
| 作品集 | 通常要求 |
| 面试 | 可能邀请线上面试 |
| 海外学生年学费 | £31,510 |
| 英语 | IELTS 6.0，单项不低于5.5 |

104 UCAS points 是资格分数体系，不应直接理解为英国统一的 A-Level 固定录取等级。

### 4. 作品集要求

这是申请过程中很重要的一部分。

学校公布的数字作品集指导包括：

- 最多10页
- 至少一件不超过3分钟的视频或动态影像作品
- 可另附最多两件不超过60秒的动态影像作品
- 展示剧本、分镜、场景设计、概念发展、拍摄计划等
- 说明本人在制作前期、拍摄期及后期中的具体角色

学校可能进一步邀请申请者参加15—20分钟的线上面试。

### 5. 毕业方向

职业方向相对明确，包括：

影视制片、摄影、剪辑、影视编剧、纪录片制作、电视演播室制作、广告与商业影像制作、声音制作等。

**适合的学生：** 喜欢影视内容创作，希望理解电影与电视两种制作环境，愿意参加团队协作，并以实际影视作品积累经验。

## 六、UAL — BA (Hons) Film Practice

- 学校：University of the Arts London — London College of Communication
- 专业：Film Practice BA (Hons)
- 中文：电影制作实践（荣誉学士）
- 学制：3年
- UCAS代码：W603
- 官方课程：[UAL Film Practice](https://www.arts.ac.uk/subjects/animation-interactive-film-and-sound/undergraduate/ba-hons-film-practice-lcc)

### 1. 这个专业与 Film and Television 的区别是什么？

虽然都属于 LCC 的影视相关专业，但 Film Practice 更集中在电影创作本身，以及电影制作中各专业岗位的协作。

学校强调通过实践学习电影制作工艺，并让学生逐步形成自己的电影创作能力和专业方向。

它尤其重视：

- 电影叙事
- 电影语言和美学
- 剧情短片与纪录片创作
- 不同制作岗位的分工与协作
- 电影从构思到成片的完整过程
- 创作理念、电影史和作品研究

注意，Film Practice 虽然重视电影创作，但不等于纯粹的个人导演专业。学校明确强调团队合作，而不是只培养以导演个人为中心的创作模式。

### 2. 三年具体学习什么？

**第一年：建立电影创作能力**

| 课程 | 主要内容 |
| --- | --- |
| Introduction to Film Practice | 电影制作基础与短片策划 |
| Documentary | 团队制作创意纪录短片 |
| Film Style | 电影风格、美学、电影语言 |
| Fiction | 剧情短片创作与不同制作岗位训练 |

在这一阶段，学生有机会学习摄影、声音、制作管理及后期等工作，同时了解电影创作中的不同角色。

**第二年：提高电影制作复杂度**

核心模块包括：

- Studio：摄影棚内的电影制作
- Story：电影故事开发
- Creative Industries：行业实践与职业发展
- Film Methods：电影创作方法
- Year 2 Film：团队完成电影作品

第二年也提供实际行业经验相关的学习机会，包括真实客户项目或实习经验等选择。

**第三年：完成毕业电影**

包括：

- Research Project（40学分）
- Graduation Film（60学分）
- Creative Careers（20学分）

其中 Graduation Film 是这一专业重要的毕业项目。

学生需要在更复杂的创作环境中完成一部电影作品，展示自己的专业能力。

### 4. Film Practice 的作品集有什么不同？

这个专业要求的作品集结构更有针对性。

根据官网：

**第一部分：电影或声音作品**

提交一份不超过3分钟的连贯作品，学校更希望看到完整场景或具有连贯性的片段，而不是单纯的精彩镜头混剪（showreel）。

**第二部分：Contextual Statement**

不超过300词，解释：

- 自己在作品中承担了什么工作
- 哪些成果最值得展示
- 喜欢哪些电影，为什么喜欢
- 对摄影、声音、美术设计等哪个方向有兴趣
- 为什么适合这个课程

**第三部分：制作过程材料**

最多8页，可以展示分镜、拍摄计划、草图、技术设计、探索过程等。

### 5. 毕业方向

- 剧情片导演或编剧方向
- 电影摄影与灯光
- 电影剪辑与声音
- 制片与影视美术
- 独立电影创作
- 电影节、发行与展映
- 继续攻读电影制作相关硕士

需要区分的是，导演等职位通常需要长期作品积累、合作经验和行业网络，不是获得该学位后就能直接担任的职位。

**适合的学生：** 对电影具有长期创作兴趣，希望制作剧情片或纪录片，愿意学习不同影视岗位，并逐步建立个人作品集。

## 七、三个媒体与影视专业到底怎么选？

最容易混淆的是 UCL Media、UAL Film and Television 与 UAL Film Practice。

| 维度 | UCL Media | UAL Film and Television | UAL Film Practice |
| --- | --- | --- | --- |
| 主要关注 | 数字媒体与新兴媒介 | 电影、电视和节目制作 | 电影创作与制作 |
| 理论学习 | 重要 | 与实践相结合 | 与实践相结合 |
| 动手制作 | 有 | 大量 | 大量 |
| 电影短片 | 有 | 有 | 核心内容之一 |
| 电视演播室 | 不是课程主线 | 有明确专业模块 | 不是主要强调方向 |
| 游戏与交互 | 重要内容 | 非主要方向 | 非主要方向 |
| AI、VR、AR | 有明确相关模块 | 非主要方向 | 非主要方向 |
| 毕业成果 | 研究与创意项目 | 影视作品集与研究 | 毕业电影与研究 |
| 主要特色 | 跨学科 | 多种影视工业流程 | 电影叙事和专业工艺 |

三个专业分别对应三种倾向：

- 想研究数字技术与媒体的关系，同时进行创意制作：UCL Media
- 想参与电影、电视、纪录片等广泛影视制作：UAL Film and Television
- 想专注于电影制作工艺、剧情片与电影创作：UAL Film Practice

这三者不存在简单的绝对优劣，关键是目标和课程匹配程度。

## 八、重点分析：同一个人申请这五个专业意味着什么？

这是整个申请组合里最关键的问题。

### 1. 这套专业组合存在明显的学科跨度

从课程内容看，五个专业之间的联系大致如下：

- 两个数学专业的知识体系高度接近。
- 两个 UAL 专业的知识体系高度接近。
- UCL Media 与两个 UAL 专业有明显的影视实践交集。
- 数学与影视之间不存在同样直接的课程重合。

因此，这份申请可以被理解为数学与创意媒体两条主线同时存在。

不过，仅凭五个选择，无法断定学生到底更喜欢哪个方向，也无法推断其申请动机。

### 2. 这五个专业能否形成合理的个人学术故事？

可以，但必须存在真实的经历支撑，而不是只靠文书把五个专业硬连接起来。

有一种可能的学术兴趣是：

Mathematics + Computational Creativity + Digital Media + Film

例如：

- 学生对几何、概率或计算数学有深入兴趣；
- 同时曾利用编程、算法、影像技术完成创意项目；
- 研究过数学模型与计算机图形学、视觉呈现之间的关系；
- 又实际制作过电影，积累了剧本、分镜、摄影或剪辑经验。

这种背景下，数学与媒体可以通过计算创意、数字影像和视觉技术建立联系。

举一个具体例子：

假设学生曾制作过一段使用程序生成视觉效果的短片。

那么学生可以从不同学科角度研究这个项目：

| 视角 | 可以研究的问题 |
| --- | --- |
| 数学 | 几何变换、数学模型、算法原理 |
| UCL Media | 数字视觉如何影响叙事与观众体验 |
| Film and Television | 如何将视觉效果整合到影视生产流程 |
| Film Practice | 如何用影像语言、剪辑与声音表达创作主题 |

这会是一个具有真实交叉学科基础的申请故事。

但需要强调：上述只是可能的案例，并不是对这位学生实际经历的判断。

### 3. 最大的问题：UCAS Personal Statement 只有一份

这是这套申请的主要风险。

英国本科通过 UCAS 一般最多选择五个专业，而这五项刚好用完五个选择。

申请者只有一套 UCAS Personal Statement，需要同时用于这些专业。

并且：

- Imperial 不接受另外提交一份替代个人陈述。
- UCL 一般也不接受修改后的或额外个人陈述，除非学校主动提出要求。
- UCL 允许同时申请两个不同的专业，但两项分别占用 UCAS 志愿名额。

2027 年入学采用三问题结构：

| UCAS问题 | 写作目标 |
| --- | --- |
| Why do you want to study this course or subject? | 为什么想学习该专业 |
| How have your qualifications and studies helped you to prepare? | 已有学术学习如何帮助你做好准备 |
| What else have you done outside education, and why is it useful? | 课外经历与专业准备 |

全文合计不超过4,000字符（含空格），每个问题不少于350字符。

#### 为什么这会造成困难？

假设申请人写了一篇以数学为主的文书：

> 我最感兴趣的是数学证明、抽象代数和数论，希望进一步探索数学的逻辑结构。

这对数学专业有明显关联，但对 UAL Film Practice 而言，可能无法充分解释为什么学生希望接受电影制作训练。

反过来，如果文书主要写：

> 我希望成为电影导演，喜欢通过镜头语言和影像叙事表达情感。

它有利于展示电影方向的兴趣，却不足以体现申请 Imperial Mathematics 所需要的数学学术动机。

而且，这种矛盾并不是简单在文书中增加几句“我也喜欢数学和电影”就能够消除的。

尤其需要注意：学校通常不会在作出录取决定时看到申请者在其他院校的全部志愿，但它们会看到同一份个人陈述。因此，问题不在于五个志愿的排列会被自动判断为不合理，而在于每个专业看到的申请论证是否足够有针对性。

## 九、如何判断这份申请到底是否合理？

下面是几种不同的实际情况。

### 情况 A：学生数学非常强，也有真实影视作品

如果学生有优秀的数学学术背景，同时已经完成过短片、纪录片或互动媒体作品，这套组合存在合理性。

但申请者仍需要准备两套不同的能力证据：

**数学方向：**

- 数学理论与证明能力
- 超出课堂要求的数学探索
- 数学阅读、研究或竞赛经验
- TMUA 等入学考试准备

**媒体与电影方向：**

- 电影或新媒体作品
- 创作过程、研究和反思
- 作品中的具体个人贡献
- 影像叙事或媒体技术方面的探索

这种学生的核心挑战不一定是能力，而是如何让两条兴趣在有限的申请文本中得到充分证明。

### 情况 B：学生数学成绩很好，但真正的兴趣是电影

这种情况下需要考虑：

为什么仍然选择 Imperial 和 UCL 的数学？

如果数学只是因为成绩好或作为其他专业的“保险”，就要理解两所大学的数学课程都具有很强的理论性，不会因为成绩达到要求就一定适合学生。

一旦进入大学，数学分析、代数、微分方程及数学证明会占据学习的主要部分。

这与长期进行电影创作的日常学习体验完全不同。

### 情况 C：学生想学数学，但影视只是兴趣爱好

此时三个传媒与影视选择是否适合，也值得重新审视。

因为 UAL Film Practice 和 Film and Television 是相当专门化的职业实践课程。学生需要完成大量制作工作，并积极参与团队项目。

如果并不希望长期从事相关创作，把它们作为纯数学专业的保底志愿，可能并不是理想策略。

### 情况 D：学生对数学与创意技术都很认真

那么 UCL Media 的确可能成为一个有交叉特点的方向。

但要理解：

UCL Media 不等于数学、计算机科学、AI 与电影四个专业的综合版本。

它以媒体理论和创意媒体实践为中心。虽然可以修读创意 AI、VR/AR 等课程，核心培养方向仍然不是高等数学。

如果学生未来明确希望做计算机图形学研究、视觉算法或机器学习工程，仍然需要比较计算机科学及相关数学、工程课程。

## 十二、对这一套申请的综合评价

这五个专业的组合，有三个值得特别关注的地方。

### 第一：数学和电影是两种明显不同的本科培养路线

数学本科主要研究抽象理论、严谨证明和数学模型。

电影本科则重点培养创意表达、电影制作工艺、叙事能力和团队协作。

虽然这些能力可以在数字创意领域相互支持，但它们不是同一种学科训练。

因此，最终选择哪个专业，本质上意味着决定未来三年主要投入在哪一种训练中。

### 第二：UCL Media 是一个有跨学科特色的选择，但无法完全替代两边

UCL Media 能够联系数字文化、技术、互动设计和影像创作。

对于有技术兴趣的创作者，它可能比较有吸引力。

但如果学生的目标是高阶数学研究，它不能替代数学 BSc；如果目标是接受完整的专业电影工艺训练，也需要与 UAL 的课程细节认真比较。

### 第三：真正需要解决的是申请叙事的一致性

如果这五个专业已经确定，我建议申请材料准备时，先整理出一份清晰的经历对应表：

| 实际经历类型 | 可以支持的专业 |
| --- | --- |
| 深入研究数学定理、证明及数学模型 | Imperial Mathematics、UCL Mathematics |
| 利用编程或算法进行视觉创作 | UCL Media，并可能支持数学的应用兴趣 |
| 制作具有完整叙事的电影短片 | UCL Media、UAL两个电影专业 |
| 参与影视团队制作并承担具体岗位 | UAL两个电影专业 |
| 研究数字媒介、交互技术与社会影响 | UCL Media |
| 将数学问题与计算影像技术结合的独立项目 | 可能同时成为数学及媒体方向的支持证据，但必须按各课程重点解释 |

这张表的意义是：从实际做过的事情出发证明专业兴趣，而不是先创造一个听起来跨学科的故事，再寻找经历去配合。

## 最终结论

如果单纯从专业之间的关系来看：

- **Imperial Mathematics 和 UCL Mathematics**：一条完整的数学申请路线。
- **UCL Media、UAL Film and Television、UAL Film Practice**：一条从数字媒体到专业电影制作的创意方向路线。
- **最明显的申请挑战**：不是五个专业不允许同时申请，而是学科跨度较大，统一的 UCAS 个人陈述需要同时回应完全不同的学术期待。

如果学生在数学和影视两个领域都有扎实的真实经历，这可以是一套有一定合理性的跨领域申请；如果主要是为了组合不同大学的名气和录取条件，则需要谨慎评估专业匹配与入学后的学习体验。

我最建议进一步核实这个学生的三项信息：A-Level/IB 的具体科目与预估成绩、是否已经有电影或媒体作品集，以及这位学生更希望从事数学研究、数字创意还是电影制作。这三点比单独比较大学排名更能判断这五个选择是否适合这位学生。
