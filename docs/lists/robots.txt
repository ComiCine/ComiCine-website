# The crawler rules below are published at /robots.txt; src/build.py appends
# a Sitemap line from config-contract.json. This file is also the source of the
# edge allow-list: every explicitly named User-agent below (everything except
# `*`) is compiled into functions/_data/gateTrust.ts as GATE_TRUST_CRAWLER_UAS,
# and those User-Agents skip the human-verification gate (see
# functions/_lib/bots.ts). They are still subject to the D1 blocklist, are never
# issued a __gate cookie and are never counted as visitors. Adding a crawler to
# the allow-list = adding one User-agent line below.
#
# The disallowed paths are endpoints and admin entry points, not content:
# crawling them only burns the site's free-tier request budget.
